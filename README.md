# ハリネル（新針マット）通しテストの共有

2026-10-27 に、ハリネル 自重指圧マット（社内の呼び名は新針マット）で、台本 → 記事 → 商品ページ（PDP）を一本の線で作る通しテストをしました。このリポジトリには、その結果と作った手順、使った仕組み（スキルの md）、元にした商品の資料をまとめてあります。

記事と PDP をよくするために見てほしいのは、次の3つです。

1. 出来上がった記事と PDP
2. どの決まりで何を決めたかの記録
3. 決まり同士がぶつかった所や、決まりが無かった所の一覧（＝「穴」）

通しの道は `3_使った仕組み/ec-ad-ops/references/flow.md` に書いてあります。今回は映像（4b）を作らず、原稿から店までを通しました。

**PDP は審査1回目で FAIL のまま止めています**（時間の都合）。残っている指摘は4件で、`04_店/審査_1.md` と `判断の記録.md` の工程4d-10 に書いてあります。仮の絵の重複、宣言の動画を探していない、poster が3コマでない、レビュー写真にマットが写っていない、の4件です。

## 記録の中の略号

記録の中のパスは、作った時のパソコンの場所で書いてあります。このリポジトリでは次の場所に当たります。

## 入れていない物

- 動画・音声のファイル、画像生成の途中の絵（`_gen/`）、作業中の画像、`.bak` の古い版
- `ec-ad-ops` のうち、今回の記事と店に関係しない部分（動画の型・静止画・古い資料）と、記事の資料の画像
- 他社のページを丸ごと保存した生の HTML（`raw/`）

スキルの md は、テストの日（2026-10-27）から変わっていません（コピーした時に、テストより新しい md が無いことを確かめました）。
