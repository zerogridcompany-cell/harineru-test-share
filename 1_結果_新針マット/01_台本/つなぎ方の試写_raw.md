# 腰痛を何のせいだと思っているか:想像の5人

## ① 会社勤めのデスクワーク男性(52歳)

1. **頭に浮かぶ順に**
   - 座りっぱなしのせいかな
   - 歳だから仕方ない
   - 運動不足で腹が出てきたせい
2. **1番目の理由:** 1日8時間は座っているし、夕方になるほど重くなる。歩くと少し楽になるのも、座りすぎだからだと思う。
3. **今していること、迷っていること:** 毎晩湿布を貼っている。昼休みに少し歩くようにした。整形外科に行こうか迷っているが、行っても「歳ですね」と言われて終わりそうで、足が向かない。
4. **本当にこわいこと:** 朝、起き上がれない日が来て、会社に行けなくなること。
5. **湿布で抑えられている?** 半分。貼った朝は動けるが、治ってはいない。ごまかしているだけだとも思う。

## ② 立ち仕事のパートの女性(54歳)

1. **頭に浮かぶ順に**
   - 立ちっぱなしのせいだよね
   - 歳のせい
   - 冷えかな。冬はとくにひどい
2. **1番目の理由:** 8時間レジと品出しで立ちっぱなし。休みの日の朝は少しましなので、仕事のせいだと思う。
3. **今していること、迷っていること:** 湿布を貼り、風呂上がりに腰を温めている。整骨院に行こうか迷っているが、お金もかかるし、パートを休むのも気が引ける。
4. **本当にこわいこと:** 立てなくなって仕事を辞めることになり、収入がなくなること。
5. **湿布で抑えられている?** 思っている。貼れば朝は動けるから、とりあえず切らさないようにしている。

## ③ 専業主婦で、親の介護もしている女性(56歳)

1. **頭に浮かぶ順に**
   - 親を起こしたり移したりするせい
   - 自分のことは後回しだから、疲れがたまってるのかな
   - 歳のせい
2. **1番目の理由:** 痛みがひどくなったのは、介護が始まってからだから。
3. **今していること、迷っていること:** 湿布を貼って、なんとかやっている。親の通院の付き添いのついでに診てもらおうかと思うが、自分の時間が取れない。
4. **本当にこわいこと:** 自分が動けなくなったら、親の面倒を見る人がいなくなること。
5. **湿布で抑えられている?** 思っていない。抑えているというより、ごまかして動いているだけ。

## ④ 自営業で車の運転が多い男性(55歳)

1. **頭に浮かぶ順に**
   - 運転で座りっぱなしだからだな
   - 若い頃に重い荷物を持ちすぎた、そのツケ
   - 運動不足で体重も増えたせい
2. **1番目の理由:** 運転して長く座ったあとは、降りるときに腰が固まる。振動もあるし、仕事柄、仕方ない。
3. **今していること、迷っていること:** 湿布を貼って、運転の合間に降りて伸ばしている。病院は、仕事を休む日がないので後回しにしている。
4. **本当にこわいこと:** 運転できなくなり、商売ができなくなること。
5. **湿布で抑えられている?** 思っている。だから貼り忘れた朝がこわい。

## ⑤ 孫の世話をしている女性(58歳)

1. **頭に浮かぶ順に**
   - 孫の抱っこやしゃがむのが続くせい
   - 歳だからね
   - 布団が薄いのか、寝方が合わないのかも
2. **1番目の理由:** 孫が来る日が続いたあとに、決まってひどくなるから。
3. **今していること、迷っていること:** 湿布を貼って、抱っこの回数を減らそうとしている。娘には言えない。病院に行くと「孫の世話をやめて」と言われそうで、迷っている。
4. **本当にこわいこと:** 孫を抱けなくなること。それと、迷惑をかける側になること。
5. **湿布で抑えられている?** 半分。朝は助かるが、夕方にはまた重くなる。

**この5人の傾向**
- 1番目に挙がったのは、昼の暮らしの中の動作や姿勢(同じ姿勢の続行、体の使いすぎ)だけでした。5人全員です。
- 「歳」は4人が挙げましたが、全員2番目か3番目で、1番目はいません。あきらめの言葉として後から出てきます。
- 朝の激痛を、寝ている間のことや朝のこわばりと結びつけた人はいません。朝は「湿布でなんとかなる時間」で、原因は昼のせいだと考えています。
- 湿布で抑えられていると「思っている」は2人、「半分」は2人、「思っていない」は1人でした。
- 本当にこわいのは痛みそのものではありません。仕事、介護、孫といった、自分の役割を果たせなくなることです。
