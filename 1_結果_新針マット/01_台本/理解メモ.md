1. **商品**：寝転んで、自分の体重で、面いっぱいの針のような突起を腰から背中に当てる指圧マット（枕・収納袋つき）（00_概要・A 1章）／呼び名「針マット」（05 0章-1）／ブランド「ハリネル」・商品名「ハリネル 自重指圧マット」（00_入口）／売値 枕 25,890円・マット 35,890円・セット 54,980円（枕＋マット＋バッグ）税込・送料無料（00_入口・05 4章）／付く物：マット・半円筒の枕・黒い巾着の袋（A 3-1）
2. **使い方と起きる事**（J-5）：床かベッドに敷く → 首を枕に、腰（骨盤の上）から背中をマットに預ける → ひざを立てると腰のくぼみまで当たる → 最初は薄い服の上から5〜10分、慣れたら素肌で1日10〜20分（台本の既定は「1日10分」05 1章）→ 乗った瞬間チクチク、最初の30秒がいちばん痛い → 2〜5分で引く → 5分をこえるとポカポカ温かい → 背中が赤くじんわり → 終わると軽い → 寝る前ならそのまま眠れる。朝の激痛には「前の晩に使う」形で言う（J-5「いつ」）
3. **根本原因**：1文「腰の激痛は、背骨の両わきの脊柱起立筋と、その奥の多裂筋の『筋肉の酸欠』」（J-3）／名前「筋肉の酸欠」（H 1章・05 1章）／鎖：同じ姿勢 → 力が入ったまま固まる → 固い膜の中で張って血管をしめつける → 血と酸素が止まる → 痛みの物質がたまって激痛 → 痛いからまた固まる（J-3 歩①〜④）。朝の場面：寝ている間ほぼ動かない（寝返り1時間1.6回）→ 止まった時間が長いほど固い → 起き上がる一瞬がいちばん固くて痛い → 数歩で引く（J-3 朝-1〜朝-6）
4. **見る人**：40〜60代、腰痛歴は年単位、毎晩湿布を貼っている（J-1）。原文：①「ロキソニンテープを貼ってないと痛みが酷く歩くのも大変です。」（#25）②「就寝前にサロンパスを貼っておくと、起床時に痛みは感じません。」（#2）③「長く貼っていると『効かなくなってきたな』と思ったり」（#26）④「痛みが強い日は湿布と痛み止め（効いているかは微妙ですが）を使用し」（#27）⑤「経験上、整形外科は毎回湿布と痛み止めを処方されるだけで無意味でした。」（責6）
5. **責めている物・今している対策**：原文で数えた何のせい（`相手の理解シート.md` C。原文集め `原文集め_湿布の腰.md`）／している事：湿布を毎晩・枚数を増やす・温める湿布に替える・痛み止めを足す（J-7・05 2章「温める湿布に替える・大きいサイズ・2枚重ねる」）／どん底の絵：引き出しは湿布だらけ（05 2章）。原文のどん底：「貼ってないと…歩くのも大変」（#25）・かぶれ（D1 ③-5）・2枚貼って胃が痛くなった（D1 ③-6）
6. **今回の相手（対策＝湿布）**：何をしている物か＝皮ふから消炎鎮痛の成分を入れ、痛みと炎症の物質づくりを抑える（D1 1章①）／どこまで効くか＝ぶつけた・ひねった直後の炎症のある痛みを数日（J-7・D1 1章の「効く場合」）／なぜ届かないか＝止めるのは鎖の最後の「痛み」だけ。固まった筋肉はゆるまず、血も流れない。だから貼っている間は楽で、はがすと元に戻る（D1 1章の推論・H 7章）。添付文書が自分で「対症療法」と書く（D1 1-1・B）／足りない物＝固まった筋肉を「押して、放す」力（血を流しこむ動き）（J-7 足した物）
7. **商品がそれをどう満たすか**：寝転ぶと体重が数千の突起に分かれ、腰から背中の皮ふを一面同時に押す → 皮ふの神経が反応して血管が広がる → その血が下の筋肉の層まで流れこむ → 酸欠の輪が切れる（J-5 働きの歩み①〜④。③は前提）／条件から商品へ：①広い面を ②手を使わず ③毎日（H 7章・05 1章）→ その形の道具が面いっぱいの突起（H 7章「原稿の道すじ」）／他にないもの：「慢性腰痛の正体は筋肉の酸欠。湿布は届いていない。寝転んで自分の体重で押す『自重指圧』のための針マット」と原因から言い切る売り手は見た範囲で0（E 3章）／競合が言っていない所：筋肉の名前・膜の中の圧・最初の30秒がいちばん痛い・押す→血管が広がる→赤く温かいの順・湿布との届く深さの比べ（I-6）
