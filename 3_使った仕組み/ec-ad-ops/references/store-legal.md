# ストアの決まりの文書（特商法・返金・規約・配送・プライバシー）

全商品共通の決まり。ウェブサイトを作る仕組みは、ここを読んで5つの文書を出す。商品ごとの値は、商品フォルダの `08_ストアの決まり.md` に書き、ここには書かない。

ひな形：`templates/store-legal/`（特定商取引法に基づく表記・返品・返金ポリシー・利用規約・配送ポリシー・プライバシーポリシー）

## 1. 返金保証の決まった形

| 項目 | 決まり |
|---|---|
| 保証の日数 | **30日**（商品到着日から） |
| 使う日数 | **15日**。到着から15日を過ぎた後でないと、申し込めない |
| 申し込める期間 | 到着から16日目〜30日目 |
| 返金額 | 支払った全額。手数料は引かない |
| 使った後の商品 | 対象 |
| 手続き | お問い合わせフォーム → 返送 → 到着を確かめてから返金 |
| 返送料 | お客さまの負担 |
| 複数点 | 同じ注文の全部を返送。保証は1注文に1回 |
| 初期不良・輸送中の破損・お届け間違い | 到着から7日以内。写真か動画を添える。送料は当社。交換・再送・返金 |

商品ごとに日数を変える時は、Seiyo が決めて、商品フォルダの `08_ストアの決まり.md` に書く。書いていなければ、上の30日・15日を使う。

## 2. 連絡先とお返事

- メールアドレスは載せない。「ご請求をいただければ、遅滞なく開示いたします」と書く。フォームで聞かれたら、すぐに教える。
- お問い合わせは、すべてお問い合わせフォームへ案内する。
- 電話番号は載せる（消せない項目）。「お電話でのご対応は行っておりません」を添える。
- お返事と返金の手続きは、営業日（月曜日から金曜日）だけ、と書く。

## 3. 文の調子

- 冷たい言い回しを避ける。「〜する義務を負いません」「責任を負いかねます」を、返金・特商法のお客さま向けの説明では使わない。
- 先に使い続けてもらう理由を書き、その後に条件を書く。理由の文は、商品理解の基盤から取る。

## 4. 同じことを、全部の場所で言う（一番大事）

次の場所の、日数・返金額・条件を、1字も違えない。1か所を変えたら、全部を変える。

1. 商品ページ・トップ・記事の保証の説明
2. カートのボタンの近くの表示
3. 返品・返金ポリシー
4. 特定商取引法に基づく表記
5. 利用規約の返品の条
6. よくある質問、口コミの文
7. 広告の原稿（商品の `05_原稿の決まり.md`）

- ページで「◯日間返金保証」と書く所には、すぐ近くに「◯日間お使いいただいた後、◯日以内のお申し込みが対象です」と「返送料のみご負担ください」を書く。条件を規約だけに書かない。
- 「全額」「返金保証」は、全額をお金で返す時だけ使う。半額やポイントで返す形にする時は、「お試し保証」などの別の名前にして、中身を同じ場所に書く。
- 「すぐ返金」「手続きなし」のような、実際の手続きと合わない言葉を使わない。

## 5. 商品で変わる所（ひな形の `{{ }}`）

| 入れる物 | どこから取るか |
|---|---|
| ショップ名・ストアURL | 商品の `00_入口.md` |
| 保証の日数・使う日数 | 1章。商品の `08_ストアの決まり.md` に指定があれば、そちら |
| 使い続ける理由の文 | 商品理解の基盤（なぜ、すぐには結果が分からないか） |
| 交換の節 | サイズや色の交換がある商品だけ。無ければ行ごと消す |
| 体に使う商品の免責 | 体に使う商品だけ。それ以外は行ごと消す |
| 支払い方法 | そのストアで実際に使える物。後払いが無ければ「入金が確認できない場合」の文を消す |

`{{ }}` を1つでも残したまま、ストアに入れない。

## 6. 出す前の点検

- 4章の7つの場所で、日数と返金額と条件が同じか。
- その商品に合わない文（別の商品から残った免責・支払い方法）が無いか。
- ストアへの書き込みは、Seiyo の指示がある時だけ。
