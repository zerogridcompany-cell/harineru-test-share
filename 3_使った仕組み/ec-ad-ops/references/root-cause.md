# 商品のルーツ（根本原因）の探し方 — 工程1の最後・全商品共通

土台は Lorenzo Pravata の記事「How to Find Your Product's Root Cause」。読んだ記録：`~/ec-ads/vsl-script-study-20261007/08_ルーツと型_読んだこと.md`、設計の原本：同じフォルダの `09_台本の設計_第2版.md`。

**根本原因とは**：「この悩みは、なぜあるのか？」を、だれも言い返せない事実に当たるまで聞いた時の、最後の答え。お客さんが思っている原因の、1つ下にある。
**なぜ要るか**：悩みを自覚している人の多くは、間違った原因を頭に置いている。その思い込みに向けて広告を作ると、同じ事を言う競合と、もう探している少ない人を取り合う。見えていない根本原因から話すと、競合が話しかけていない層に届く。原稿の「本当の原因はここ。だから今までの対策は効くわけない」は、ここで決めた1つから書く。

- **いつ**：商品理解の基盤（A〜G）がそろった直後。初日の設計・アングル・原稿より前
- **だれが**：本体（Claude Code）が A〜G から組み立てる。新しい調査は、出どころが足りない所だけ
- **書く所**：`newec_harness/<商品名>/01_商品理解の基盤/H_根本原因.md`（形は9章）。00_概要 の「1ページの結論」に1行足す
- **承認**：Seiyo が1つ（多くて2つ）に決める。ダッシュボードの自動の立ち上げでは、止まらずに案として書き、まとめの「承認してほしいこと」に出す
- 根本原因が決まっていない商品は、VSL の原稿（[vsl-script-design.md](~/.agents/skills/ec-ad-ops/references/_archive/台本の作り方_20261008/1_VSLの台本の型（14段）/vsl-script-design.md)）を書き始めない

## 1. 症状を並べる（お客さんの言葉で）
B（お客さんの言葉）から、「ここがおかしい」と言っている事を5つ前後、原文の番号つきで並べる。分類の名前（肩こり）だけでなく、起き方（「三日で元に戻る」「何をしても」）も入れる。

## 2. 責めている物を拾う（間違った診断）
B の言葉・レビュー・知恵袋・問い合わせ・調査から、**何かのせいにしている文**を原文で抜く。

| 拾う物 | 例 |
|---|---|
| 自分を責める文 | 歳のせい・意志が弱い・体質・運動不足・自分が下手 |
| 物や人を責める文 | あの商品はだめ・全部詐欺・当たり外れ |
| 専門家に言われた事 | 「異常はありません」「様子を見ましょう」 |
| 試してだめだった対策 | 物の名前で（D の対策の一覧と合わせる） |

表にする：悩み｜責めている物｜原文｜出どころ。**見る人がいちばん自信を持って信じている物**に印を付ける（フックはここから入る）。
最初の「なぜ」の答えは、ほぼいつもこの「責めている物」で、根本原因ではない。ただし調査の中でいちばん役に立つ。広告がどの思い込みを変えればいいかを、そのまま教えてくれる。

## 3. 木を書く（「なぜ」を掘る）
```
症状（お客さんが言う事）
 ↓ なぜ？
責めている物（2章）
 ↓ なぜ？
実際に起きている事（体の中・物の中・業界の中で）
 ↓ なぜ？（だれも言い返せなくなったら止める）
根本原因
```
- 各段に、出どころ（01 のどのファイルのどこか）を書く
- 候補は1つにしぼらず、出るだけ出す（商品の仕組み A・強み E・対策の欠点 D から、別の枝も書く）

## 4. 箱を確かめる
根本原因は、必ず次の3つのどれかに入る。入らない答えは、まだ途中か、ただの言い分。

| 箱 | 中身 | 例（記事から） |
|---|---|---|
| 体 | 体は、自然にこうなる | 60歳を過ぎると、骨をこわす細胞が、直す力を上回る（骨粗しょう症。責めている物は「カルシウム不足」） |
| 物 | 物・素材は、こうふるまう | 鉄は、水と空気に反応してさびる（持ち主の手入れのせいではない） |
| 市場 | 業界が、こう出来ている。そのせいで、お客さんが受け取る物が変わる | 「独自ブレンド」は成分の量を書かないので、びん同士を比べられない |

## 5. 止めてよいかのテスト
| # | テスト | 確かめ方 | 出どころ |
|---|---|---|---|
| ① | 全部の症状が、そこから説明できるか | 1章の症状を1つずつ当てて ○×。5つのうち2つしか説明できないなら、止めるのが早いか、商品が違う | 記事 |
| ② | お金のテスト | 今日お金を払ってでも消したい問題か。もう何かにお金を払っている証拠を、B・D から書く | 記事 |
| ③ | 仕組みで言えるか | 「何が → どうなって → どうなる」を3〜4歩で書けるか。「頭皮です」の一言だけは、ただの言い分で、今月10個目の言い分として聞き流される | 記事 |
| ④ | 今までの対策が届いていない、と言えるか | D の対策を1つずつ、「何をしている物か → だから根本原因のどこに届かないか」1〜2文で書けるか | Seiyo の流れ |
| ⑤ | 商品が届く、と言えるか | A・E の仕組みで、「この商品は、根本原因のここに、こう届く」が1文で書けるか | Seiyo の流れ |

①〜③に落ちたら、もう1段「なぜ」を掘る。④⑤に落ちたら、その根本原因は本当でも、この商品の広告には使えない（別の候補へ）。

**正直な答えが「この商品は症状を軽くするだけで、下には何も無い」なら、そう書く。** その商品の広告は、もう探している人にしか効かない。新しい層にお金を使う前に分かる。

## 6. 良い根本原因の条件と、だめな例
**良い根本原因**
- 1つ（言葉も1つ。原稿の中で言い方を変えない）
- 見る人がまだ聞いた事のない事（「だれも教えてくれなかった理由」）
- 名前がある（体の言葉か、自分で付けた短い名前。記事の例：「ゾンビ細胞」「線維芽細胞の働きの落ち込み」。髪なら DHT、体重ならコルチゾール）
- 責めを、本人からも、今まで買った物からも外せる（「あなたが悪いのではない。前の対策は、ねらう所が違っただけ」。これが「もう一度試してみよう」の扉を開け直す）
- 5章の5つを通る

**だめな例**
| だめな例 | なぜだめか |
|---|---|
| 返金保証・安さ・送料無料 | 買う直前の不安を消す物。買う理由ではない |
| 「業界が不透明」「ほかは質が悪い」 | 言い分。それを直すためにお金を払う人はいない |
| お客さんが責めている物そのもの（歳・姿勢・カルシウム不足） | それは木の2段目。もう1段下がある |
| 症状の言い換え（「こっているから痛い」） | 何も説明していない |
| 一言だけで仕組みが無い（「頭皮です」） | 聞き流される |
| 商品の特徴の裏返し（「突起が無いから」） | 自分の都合。体・物・市場の事実ではない |
| 2つ以上を並べる | 原稿で論が割れる。アングルごとに言う事がばらばらになる |
| 全部の症状を説明できない事実（「背中は手が届かない」） | 事実だが、悩みの理由ではない。根本原因ではなく、原稿の「自分では見えない」「どう違うか」の段で使う |

## 7. 候補に順位を付けて、1つに決める
候補ごとに、箱・5章の○×・出どころの有無を表にする。1位を根本原因にする。**外した候補は捨てず、「原稿のどの段で使うか」を書く**（見えない理由・対策が届かない理由・商品の違い、に回る事が多い）。

## 8. 原稿に渡す形にする
1. **名前**と、**その場で言う一言の説明**（専門の言葉は「専門的には『◯◯』と言います。△△、という意味です」）
2. **仕組み3〜4歩**（1歩＝短い1文）
3. **たとえ**を3つ考えて、1つ選ぶ（2026-10-07 Seiyo「原因の話をしている時に、『これは、こうしているようなものです』という例えを入れた方が強い」）。選ぶ条件：
   - 見る人が**自分の体で知っている事**（その場で試せると、なお強い）
   - 根本原因の仕組みと**同じ形**（何が → 何を止めて → どうなる）
   - 同じ絵のまま、**今までの対策を置ける**（「〜したまま、〜しているようなもの」）
   - 同じ絵のまま、**商品の働きを置ける**（解けた時の感じが言える）
4. **今までの対策が届かない理由**（対策ごとに1〜2文。D の出どころつき）
5. **治すための条件**（2つまで。根本原因の裏返しで、今までの対策に欠けていた物）
6. **商品がどう届くか**（条件に1つずつ答える1文）
   - 5と6は、原稿では「解決の仕組み」と「商品の誕生」（アーカイブの vsl-script-design.md の8・9段）になる。**商品の名前を出さずに**、やる事は1つ（根本原因を裏返す動き）→ ヴィランに無い物 → 道具の条件（原因から出る壁を3つ）→「どうやるか」→ 押し方を変えた → 道具の形 →「それが◯◯です」、の順で言えるように書いておく。引用・試験の数字は原稿の声に入れない（2026-10-07 Seiyo）
7. **アングルへの広げ方**：1つの根本原因から、認知の段階ごとに1アングル

| 段階 | 広告のする事 | フックの形 |
|---|---|---|
| 無自覚 | 思い込みを変える | 「（症状）の本当の原因は、（責めている物）ではないと、知っていましたか。」 |
| 悩み自覚 | 悩み → 一般的な解決 → 独自の仕組み | 根本原因を事実として言う：「（条件）になると、（体・物）は（こうなる）。」 |
| 解決策探し | 今の対策がなぜ違うか（独自の仕組みを厚く） | 「（対策）を（どれだけ）しても、（症状）が治らない人へ。」／話し手がいる時「ずっと、（責めている物）のせいだと思っていました。」 |

- アングルが違っても、**根本原因は同じ1つ**。変えるのは、入口（何を責めているか・何を試したか）と、たとえ
- 人の層は、年齢・性別より「**何を責めているか・何を試したか**」で分ける（F の表の入口に書き足す）
- 実際の広告の文でないフックは、出すまで仮説
- どのアングルでも骨組みは同じ：思い込みに名前を付ける → 本当の原因につなぎ直す → 仕組みを見せる → **その後で初めて**、商品を「本当の原因に届く物」として出す

## 10. この手順が直さない物
| 直さない物 | どうするか |
|---|---|
| 急ぐ理由 | 根本原因は「後で買う」を消さない。待つ事の代償・今買う理由は別に入れる（アーカイブの vsl-script-design.md の7段・14段） |
| 形式 | 同じ根本原因でも、見た目が同じ広告は飛ばされる。アングルごとに見た目を変える（基盤の pack の決まり） |
| 解決策探しの人 | 根本原因の言い直しだけでは足りない。「今の対策がなぜ違うか」を厚くする（アーカイブの vsl-script-design.md の6段：ヴィランはなぜ届かないか） |
| 例のかたより | 記事の例は全部「体」の箱。物・市場の箱は例が少ないので、テスト②（お金）をとくに確かめる |
