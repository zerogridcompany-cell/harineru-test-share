# 新しい型の作り方

棚に無い型を言われた時（「◯◯が話している系で」「◯◯みたいな感じで」）、棚の型がどれも合わない時に、ここで型を作る。

## 作る前に決める事（4つ。紙に書く）
1. **語り手**：立てるか、立てないか。立てるなら、役。口ぶり
2. **何で引っぱるか**：見る人が、最後まで見る理由を1行で（こわさ・裏側・なぞ・自分に当たる・順位 など）
3. **運ぶ順**：部分を7〜10に分け、それぞれ「伝える事」と長さを書く。段階の芯の「通る点」が、どの部分に入るかを確かめる（全部入っていなければ、型として使えない）
4. **書き出しの入り方**：この型らしい1文目は、どんな入り方か

## ユニークな型の考え方（棚の型の言いかえにしない）
**ほかの世界の「形」を借りる。** 見る人が、ほかの所で見なれている形に、台本を流しこむ。借りる先の例（ここに無い物も、自分で考える）：
- 知らせの形：ニュースの速報／天気予報／注意書き・取り扱いの説明書
- 調べる形：事件の調べ（犯人はだれか）／裁き（どちらが悪いか）／実験の記録
- 時間の形：カウントダウン／日記／1日の時間割／◯年後からの手紙
- 比べる形：順位（下から上へ）／2人を並べる／する前とした後
- やりとりの形：よくある問い合わせ／先生と生徒／見る人の心の声との会話
- 中からの形：困り事の起きている所（物・体の一部）が、自分で話す

**形を選ぶ前に、中身の質 8-3 の「対応の表」と「あらすじ3文」を、候補の形3つで書く。** `型/使った形の一覧.md` にある形は使わない（下の「良かった形に共通していた事」は読む）。**候補は、まず「一番ユニークな物」から3つ出す**（おとなしい形・よくある見立てを候補にしない）。その3つの中で、5行がうまり、出る動作と商品が一番きれいに重なる形を選ぶ。3つとも表がうまらなければ、候補を出し直す（ふつうの形に下げない）。借りた形の中で、人や物が話す時は、中身の質 8-2（話し手の札・口ぶり）を当てる。

借りた形の「お約束」（言い回し・区切り方）を、最後まで守る。途中でふつうの説明に戻らない。ただし、段階の芯の通る点は全部通す。

## 型のファイルの形
```
# 型：<名前>
- 向く段階：
- 語り手：
- 何で引っぱるか：
- 見本：<OK が出た台本の置き場所。まだなら「まだ無い」>
- 成績：
## 運ぶ順（表：# ｜部分｜伝える事｜長さ）
## 案を出す場面
## 外しやすい所
```
- 型のファイルに、商品の中身・文の型・見本の文を書かない
- 書いた台本に Seiyo の OK が出たら、ファイルを `型/` に置く。OK の前は、作業のフォルダに置く
