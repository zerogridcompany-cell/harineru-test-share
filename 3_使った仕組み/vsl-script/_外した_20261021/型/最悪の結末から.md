# 型：最悪の結末から

- **向く段階**：①・②（運ぶ順の表は段階②の形で書いてある。ほかの段階で使う時は、語り手と引っぱる物だけを借りて、その段階の芯の通る点を通す）
- **語り手**：立てない（ナレーション）
- **何で引っぱるか**：こわさ。放っておいた先を最初に見せて、「今ならまだ戻せる」へ運ぶ
- **見本**：まだ無い
- **成績**：まだ無い

## 運ぶ順
| # | 部分 | 伝える事 | 長さ |
|---|---|---|---|
| 1 | 書き出し | 困り事を放っておいた先に、その場所そのものがどうなるかを言い切る（中身の質 4-1。暮らしの不便で言わない） | 1文 |
| 2 | 今のあなた | 今の困り事（その人の一番強い言葉で）。困り事を軽く言わない。何のせいだと思っているかを否定する | 2〜3文 |
| 3 | 原因 | 見えない所で、何が、どうなって、困り事が起きるのか | 厚く |
| 4 | 進み方 | 放っておくと、原因がどう進んで、1の姿に着くか。段を追って（今 → 次 → その次）。見えない所で起きる事として、言い切る | 厚く（3と合わせて全体の半分） |
| 5 | 分かれ道 | まだ戻せる理由（こわれたのではなく、止まっているだけ など）。戻すのに要る事を1つ | 2〜3文 |
| 6 | 商品 | それをする物。名前はここで初めて | 1〜2文 |
| 7 | 使うと起きる事 | 3の逆 | 3〜4文 |
| 8 | 最後の姿 → 締め | 姿は、1の逆の場面 | 2文＋3文 |

## 外しやすい所
- おどしだけが続いて、原因の説明が薄い
- 4の段が、暮らしの不便の並びになる（その場所の中で、何が進むかで言う）
