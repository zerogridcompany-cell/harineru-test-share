# 型：している事が、悪くしている（もとの名前：まちがい3つ）

- **向く段階**：②・③（運ぶ順の表は段階②の形で書いてある。ほかの段階で使う時は、語り手と引っぱる物だけを借りて、その段階の芯の通る点を通す）
- **語り手**：立てない（ナレーション）
- **何で引っぱるか**：「良いと思ってしている事・何もせず待っている事が、その間ずっと、悪くしていた」。見る人の毎日の動作を並べるので、「見られていたのか」となる
- **見本**（2026-10-08 Seiyo「めっちゃいいやんけ」）：`~/ec-ads/harimat-script-20261008/段階2_7本目/` の台本（言い回しは写さない。運び方だけ見る）
- **成績**：まだ無い

## 運ぶ順
| # | 部分 | 伝える事 | 長さ |
|---|---|---|---|
| 1 | 書き出し | 困り事の場面＋「そうしているほど、悪くなる」を、強い結末で言い切る | 1文 |
| 2 | している事を並べる | 見る人が、その困り事に対して毎日している事・していない事を、**動作で、短く、2〜3個**。最後に、「その間ずっと、見えない所では〜」と、書き出しをもう1度強く言う | 3〜4文 |
| 3 | 原因 | 原因を1文で言い切る → 3〜4歩 | 厚く |
| 4 | している事に戻る | 2で並べた事を、原因の言葉で1つずつ受ける。だから良くならない・悪くなる。かたまりの終わりは、困り事の言葉に戻る。最後に、結末を段を上げて言う | 厚く（3と合わせて一番厚い） |
| 5 | 要る事 | 原因を解くのに要る事を1つ。自分でやろうとして、なぜ出来ない・続かないか。終わりは、困り事の言葉に戻る | 3〜4文 |
| 6 | 商品 | それを、手間なくするのがこの商品。名前はここで初めて | 2文 |
| 7 | 使うと起きる事 | 見えない所で何が起きるか。使った時にどう感じるか | 4〜6文 |
| 8 | 最後の姿 → 締め | | 2文＋3文 |

## 外しやすい所
- 2の動作が、言いかえの並びになる（3つとも同じ事。ちがう時刻・ちがう動作にする）
- 4で、2の事を受けずに、別の説明を始める
- している事を、買った対策にすると段階③になる（②では、何もしない・待つ・がまんする・自己流の小さな事）
