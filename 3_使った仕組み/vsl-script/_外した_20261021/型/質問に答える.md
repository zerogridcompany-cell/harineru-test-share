# 型：質問に答える

- **向く段階**：②・③・④（運ぶ順の表は段階②の形で書いてある。ほかの段階で使う時は、語り手と引っぱる物だけを借りて、その段階の芯の通る点を通す）
- **語り手**：立てない（ナレーション）。見る人が心の中で聞く質問に、1つずつ答えていく
- **何で引っぱるか**：「それ、ずっと気になっていた」。質問が次の質問を呼ぶ
- **見本**：まだ無い
- **成績**：まだ無い

## 運ぶ順
| # | 部分 | 伝える事 | 長さ |
|---|---|---|---|
| 1 | 書き出し | 1文目は、結果の言い切り（中身の質 4）。2文目で、その人がずっと思っている事を質問の形で1つ（人物メモの言葉から）。すぐに答えを言い切る | 3文 |
| 2 | 質問1「なぜ、こうなるのか」 | 原因。見えない所で、何が、どうなって、困り事が起きるのか | 一番厚く |
| 3 | 質問2「なぜ、◯◯しても良くならないのか」 | その人が信じている事・している事が届かない理由を、原因の言葉で | 2〜4文 |
| 4 | 質問3「放っておくと、どうなるのか」 | 続けた先 | 2〜3文 |
| 5 | 質問4「じゃあ、どうすればいいのか」 | 要る事を1つ → 商品。名前はここで初めて | 2〜3文 |
| 6 | 質問5「それで、何が起きるのか」 | 使うと、見えない所で何が起きるか。使った時にどう感じるか | 3〜4文 |
| 7 | 最後の姿 → 締め | | 2文＋3文 |

- 質問は、声に出して読む短い1文にする（「では、なぜ〜」のような進行の言葉は付けない）。質問の数は3〜5

## 外しやすい所
- 質問が、見る人の言葉ではなく、説明の都合で作られている
- 質問ごとに話が切れて、原因の線が1本になっていない
