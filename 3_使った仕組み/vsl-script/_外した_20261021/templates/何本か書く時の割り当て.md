# 何本か、同じ切り口で書く時の割り当て（人に書かせる時も、これで渡す）

同じ日に、同じ商品・同じ切り口で、2本以上書く時は、**書き始める前に、下の表をうめる。** 別々に書くと、相手・思いこみ・形・書き出しが重なる（実際に重なった）。2026-10-10 に Seiyo が「アウトプットがすごく良かった」と言った4本は、この割り当てで書いた。

**依頼票がある時**（2026-10-11）：票1枚＝書く人1人＝下の表の1行。段階・映像の型・寄せ方は、票のとおり。渡す文（2章）に、票のファイルの場所を入れる。場面は、票の「相手の指定」とアングルのページ（J-1）から取り、同じ pack の票どうしで重ならないように、票の「ほかの票と変える物」で分ける。

## 1. 割り当ての表（1本に1行）
| 本 | 段階 | 場面（いつ・どこで） | 型 | 借りる形の群（ユニークの時） | 書き出しのこわさの種類 |
|---|---|---|---|---|---|
| 1 | | | | | |

- **場面**：1本ずつ、ちがう場面にする（時刻・している事で分ける）。場面は、切り口の小さい基盤の「困り事の場面（多い順）」から取る
- **型**：1本ずつ、ちがう型。棚の型は、候補を2〜3つずつ、重ならないように分けて渡す。ユニークは、借りる形の群（知らせ／調べる／時間／比べる／やりとり／中から）を分けて渡す。`型/使った形の一覧.md` にある形は、使わない
- **書き出し**：軸の種類（今、強いと言われている物）と、別の種類を、半分ずつ（3本なら、1本は別の種類）。全部の本に「書き出しの替え」を2つ
- 思いこみは、割り当てない（場面ごとに、原文を数えて決まる）。出た後に、重なっていないかを見る

## 2. 書く人（別の Claude）に渡す文に、必ず入れる物
1. スキルの入口（`SKILL.md`）と「読む順を飛ばさない」
2. 商品・段階・切り口・自分の場面・ほかの本の場面（重ならないように）・型（または形の群）・長さ・行き先・今日の日付と季節
3. 切り口の小さい基盤を先に作る事（`相手を1人に決める.md` 2-2〜2-4）。さがす言葉の例は、**相手がふだん言う言い方**で3〜5個（専門の呼び名・「何のせいか」の言葉を入れない）
4. 書き出しの割り当て（軸か、別の種類か）と、直前の台本の書き出し（台帳に足していない物があれば、その置き場所）
5. Seiyo の直前の指摘があれば、**言葉のまま**と、それが当たる手順書の節
6. 作業フォルダ（1本に1つ）・置くファイル（`台本.md`・`理解メモ.md`・`相手.md`。`台本.md` は `出力の形.md` の全部。2026-10-11 に1つにそろえた）・変えてはいけない物（商品のフォルダ・スキル）。**商品のフォルダを書きかえない時は、出力の一番下に「台帳に足す1行」を書いて返す**（足すのは、渡した側）
7. 「直してほしい所・注を付けて返さない。検品を全部通してから出す」
8. 返す物：出力の形＋数えた表（思いこみの件数と段階）＋形の対応の表（ユニークの時）＋書き出しの確かめ＋迷った所

**入れない物**：答え（思いこみ・形・書き出しの文）を先に書いて渡さない。言葉の例（強い言葉の例など）を、渡す文に書かない（その言葉に寄る）。

## 3. 返ってきたら、自分で見る物
- 段階がぶれていないか（対策の名前が、書き出し・否定する物に入っていないか）
- 思いこみ・形・書き出しの着地が、本どうしで重なっていないか
- 資料に無い使い方・仕組みの文が、一覧になっているか
- 文のつなぎ（急に新しい話が出る文が無いか）
- 台帳と記録に足す（Seiyo が採った物に印）。使った形を `型/使った形の一覧.md` に足す
