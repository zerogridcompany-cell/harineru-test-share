### 3-5. 1文の中でも、段を飛ばさない（短くする、と、分かりやすくする、は別の事）
- **1文の中で、鎖の段を飛ばさない。** 「A だから C」と言う時、間の B を、同じ文か直前の文で言っている事。とくに、**困り事（痛み）を何かのせいだと言う文は、痛みの直前の段（酸素が切れる）を言ってからでないと言えない**。「血が減った筋肉を伸ばしたから痛い」は、血 → 酸素 → 痛み の「酸素」を飛ばしている
- **名詞に詰めない。** 「血の減った筋肉」「固まった腰の奥の筋肉」のように、鎖の段を連体修飾（「〜した◯◯」）で名詞の中に押しこむと、見る人はその段を飛ばして読む。段は、**動詞のある文で、起きた順に**言う。1文に出来事は2つまで。連体修飾に動詞を2つ以上重ねない（「ひと晩、血の減った筋肉を、無理に伸ばした」は3つ）
- **字を削る時に削ってよい物**：形容・言い直し・同じ場面の2回目・あおりの言葉。**削ってはいけない物**：鎖の段・段と段をつなぐ言葉（「だから」「すると」「その筋肉を」）・原因の名前。字数が足りなければ、段5か段7を薄くする（鎖を削らない）
- **確かめ方**：1文ずつ「この文の中に、鎖の段がいくつ入っているか」を数える。3つ以上なら分ける。「〜から」「〜ので」「〜すると」の前後が、鎖で隣り合う段か。隣でなければ、間の段を入れる。試写の問い9（「なんで、そうなるの？」）は、文と文の間だけでなく、1文の中の2つの事の間も聞く

### 3-6. 日本語の自然さ（文の形。書いた後に1文ずつ見る）
中身が正しくても、形が不自然だと「どういうこと？」になる。次の4つは、書き手（AI）が毎回まちがえる形。1文ずつ見て直す。
| # | 形 | だめな例 | 直し |
|---|---|---|---|
| ① | **並べる物は、同じ形にそろえる。** 「AでもBでもない」「AかBか」「AとB」の A と B は、同じ品詞・同じ語尾（〜からでも／〜からでも、〜せいでも／〜せいでも、〜しても／〜しても） | 「なめているからでも、反抗でもありません」（動詞句と名詞） | 「なめているからでも、反抗しているからでもありません」 |
| ② | **否定の文には、主語を置く。** 「〜せいではありません」「〜わけではありません」は、だれの何が、を言う。名詞を切り詰めない（「夜のがまんが弱い」は、だれのがまんか分からない） | 「夜のがまんが弱いせいでも、年でゆるんだせいでもありません」 | 「愛犬が、夜のがまんが苦手なわけでも、年でゆるんだわけでもありません」 |
| ③ | **「〜ても」「〜のに」「〜が」の対比は、同じ物差しで。** 「AはXできなくても、BはXできる」のように、前と後ろの動詞をそろえる。前で「取れない」と言って後ろで「作れる」と言うと、対比に見えずに矛盾に聞こえる。対比でないなら、2文に分けて「でも」でつなぐ | 「ラグの目印は取れなくても、犬が選ぶ目印は、作れます」 | 「ラグの目印は、消せません。消す代わりに、ラグより強い目印を、別の場所に作ります」 |
| ④ | **感覚の言葉と、体の場所を合わせる。** 鼻なら「におう・分かる・かぎ分ける」、目なら「見える」。「犬の鼻には〜に見える」は、ひっかかる（試写で3人が「目ではなく、と言ったのに見える」）。言い回しとして使う時は、本文で1回まで | 「犬の鼻には、ラグの方が、トイレに見えている」 | 「犬の鼻には、ラグの方が、トイレのにおいがする」「犬は、鼻で、ラグをトイレだと決めている」 |
- **見つけ方**：書いた後、1文ずつ、「だれが・何が」（主語）と「何と何を並べているか」を横に書く。主語が無い否定の文、並びの形がちがう文、「〜ても」の前後の動詞がちがう文に印を付けて直す
- **別エージェントの「日本語の検品」**（`templates/相手役の試写.md` の末尾）を、本試写の前に1回通す。決まりも商品も知らない読み手に、「日本語として変な文」だけを番号で出させる。1人でも変と言った文は直す
- 読みの注（`templates/出力の形.md`「声に出して読まれる台本として書く」）は、これとは別に、読みと間の確かめ

（2026-10-19 Seiyo「掃除機をかけるために腰の激痛を感じている主婦が、骨盤のゆがみのせいかな、と思うのは考えにくい。整体師でない限り、腰の激痛が骨盤から来ているとは基本は思わない。やっぱり腰なのかな、腰だから仕方ない、が一番多い。産後の人なら、産後だから痛いのかな。こういう状況で腰が痛かったから、じゃあこれが原因なんじゃないか、という一般人のつなぎ方が下手。相手が今どう思っているのか、の思考が弱い。どのプロダクトでも同じ事が起きないように、ルールから」。**第3.4版までの決め方「C の上位から順に鎖と照らし、鎖に無い物が最初に出た物を否定する」は、相手が思っていない物（骨盤・マットレス・寝具）を1文目に置く決まりだった。取り消す。** 何が起きていたか：06 で「年」を否定して鎖と矛盾した後、矛盾をさけるために「鎖の外」を先に見る決まりにした。すると、相手の上位（年・姿勢・使いすぎ）が全部「鎖の中」になり、書き手が鎖の外の物（骨盤）をさがして C に書き、相手役の口ぐせにもそれを書いたので、試写でも見つからなかった）

**順番は、相手 → 鎖。** 否定する物は、相手が今、本当に思っている物（相手の理解シート C の1位）。鎖の表は、その後で、その物を段に使わずに組む。鎖の都合・資料の予定・ほかの台本との重なりで、否定する物を替えない。

1. **C の候補は、一般の人のつなぎ方で出す。** 一般の人は、「こういう場面で痛かった → じゃあ、これのせいかな」と、場面のすぐそばにある物・自分の体の弱い所・あきらめの一言でつなぐ。候補は、この3つの箱から出る：

| 箱 | 中身 | 例（相手の言い方のまま） |
|---|---|---|
| ア 体の側の見立て | 自分の体の、どこが・なぜ、と思っている物 | 「やっぱり腰なのかな」「腰が弱い」「年かな」「産後だから」「体質」「冷え」「運動不足」「うちの子は頭が悪い」 |
| イ あきらめの結論 | 見立てに付けている結論 | 「腰だから仕方ない」「年だから付き合うしかない」「そのうち治る」「まだ子犬だから、そのうち覚える」 |
| ウ きっかけ | 場面の動作・物 | 「掃除機のせい」「かがんだから」「使いすぎ」「姿勢が悪い」「マットレスが合わない」「ケージが狭い」 |

専門の言葉（骨盤のゆがみ・筋膜・自律神経・フェロモン・マーキング）は、相手がその言葉を自分から口にしている原文が3件以上ある時だけ候補にする。商品の資料が「このアングルでは◯◯を否定する」と予定していても、相手が思っていなければ使わない（10 掃除機：H 表5 の「骨のゆがみではありません」をそのまま使った）。

2. **数える。** 原文で数える（`相手を1人に決める.md` 2-3・2-4）。原文が3件に足りない時（仮のシート）は、**つなぎ方の試写**（`templates/相手役の試写.md`「つなぎ方の試写」。場面だけを渡し、何のせいだと思っているかを、その立場の5人に言わせる。C・E・商品・鎖は渡さない）を先にして、その1位〜3位を件数の代わりにする。配信の前に原文で数え直す。**書き手の見立てで C を埋めない**（17 子犬「そのうち覚える」は原文0件で書いた）。

3. **1位を否定する。** 1文目は、相手の言い方のまま（「腰だから仕方ない」「年のせい」）で取り上げる。言い方を専門の言葉に置きかえない。次の文は、痛みの直前の段の原因（4-1 ③）。

4. **1位が ウ（きっかけ）の時は、きっかけそのものを否定しない。** きっかけは鎖の段1（場面）なので、「掃除機のせいではありません」と言うと、段4で「掃除機を押すから丸まって張る」と言う事になり、矛盾する（07 首「姿勢」）。その時は、相手がそのきっかけに付けている **イ（結論）か ア（場所）** の方を、相手の言い方で否定する：

5. **鎖の表は、否定する物を段に使わずに組む。** 「年のせいではない」と言うなら、「年とともに寝返りが減るから」の段を作らない（06 の矛盾）。年・寒さ・体質・運動不足は、鎖の段にせず、「輪が回りやすくなる条件」として記事に回す。きっかけ（姿勢・掃除機・使いすぎ）は段1に置くので、4 のとおり否定しない。**否定する物を段に使わないと鎖がつながらない時だけ**、否定型をやめて、別のフックの形（体の中の実況・意外な事実・しのぎ方の否定・時間の巻き戻し）にする。その時 ①の声（あなたのせいではない）は、段4の終わりで「体はだれでもこうなる」（根本原因の箱＝体）の形で言う。**鎖の外の物をさがして、代わりに否定する事はしない**

8. **しのぎ方の否定**（「回しても、もんでも、その時だけ」）は、原因の否定ではないので、鎖の中の事でも言える。ただし「〜しても消えない」が資料で言える事に限る
