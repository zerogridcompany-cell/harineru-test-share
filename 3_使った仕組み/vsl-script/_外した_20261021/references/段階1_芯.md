# 段階① 気づいていない人への台本 — 芯

**相手**：困り事を、困り事だと思っていない。小さなサイン（軽い不調・小さな不便・ちょっとした失敗）は出ているが、「こんなものだ」「みんなそうだ」と流している。原因も対策も、考えた事が無い。
**頭の中**：「別に困ってない」「まあ、こんなものやろ」。
**動かす一歩**：「これは、放っておいたらあかんやつや」。
**書く相手は、この段階の中の1人**（人物メモ）。

ここが決めるのは、どの型で書いても通る点だけ。並べる順・だれが話すか・何で引っぱるかは、型（`型/`）が決める。

## 1. 通る点（6つ）
| # | 見る人の頭の中 | 中身 |
|---|---|---|
| 1 | 「え、それ、私もある」 | 人物メモの**小さなサイン**（本人が気にしていない、毎日のちょっとした事）を、本人の言葉で言い、すぐ強い結末につなぐ。**困り事の名前では呼びかけない**（本人は、自分がその困り事の人だと思っていない） |
| 2 | 「こんなもの、ではなかったのか」 | 「こんなものだ」と流している理由（年・みんなそう・昔から など）を、1つ否定する |
| 3 | 「中で、そんな事が起きていたのか」 | サインの正体。見えない所で、何が、どうなっているか。原因を1文で言い切り、3〜4歩 |
| 4 | 「放っておくと、こうなるのか」 | **ここが一番厚い（全体の3〜4割）。** サインが、どう進んで、商品の「困り事の言葉」（一番強い言葉）の所まで行くか。段を上げて言う。今のサインが、その入口だと分かる |
| 5 | 「今なら、まだ簡単に止められる」 | 早い今だから出来る事を1つ。商品は、それをする物として、短く出す。**商品の名前は、後ろ3分の1で初めて出す** |
| 6 | 「見てみよう」 | 最後の姿（サインが出ない毎日）→ 締め |

## 2. 段階①の決まり
- **中身の質 2-1（困り事は一番強い言葉で）は、結末の側に当てる。** 今のサインは、本人の感じ方のまま（軽くてよい）。そのサインの先にある物を、一番強い言葉で言う。サインそのものを大げさに言うと、「私はそこまでではない」と外れる
- 人物メモの中心は、困り事の場面ではなく、**気にしていない小さなサインと、流している理由**
- 対策の比べ合いをしない。対策の名前を出さない（まだ何も探していない人）
- 原因（3）は、全体の2割まで（1文＋3〜4歩。長くしない）。型の運ぶ順の表が「原因を厚く」と言っていても、この段階では 4 が一番厚い
- 4 の進み方は、お客さんの原文にある「もっと進んだ人の言葉」を段にして使う（今のサインの人 → 続くようになった人 → 一番強い言葉の人）
- 商品の説明は短く（全体の2割まで）。売りこまない。ただし、締めは共通の形で必ず入れる
- 長さ：指定が無ければ 900〜1,100字
