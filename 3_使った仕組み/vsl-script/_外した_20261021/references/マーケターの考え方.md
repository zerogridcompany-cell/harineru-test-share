このスキルの決まりは、2つの強さに分かれる。**混ぜない。**

| 強さ | 中身 | 扱い |
|---|---|---|
| **固い（外さない）** | ①相手（理解シートで数えて決めた1人）②その台本の受け持ちの「15の心の声」（`15の心の声.md`・`記事と分ける.md`）③人数・割合などの事実は、ある程度調べてから言う。強調・誇張はしてよい（技術テスト。`中身の質` 11）④同じ説明を2回しない（`中身の質` 2-7）⑤1文ずつ、伝えたい事と字の意味が合う（`中身の質` 2-4）⑥着地が記事なら「まだ話せていない事」で渡す（`記事と分ける.md` 4-2）**⑦因果の鎖に、飛んだ段が無い**（2-2 の表を先に作り、本文の文はその段を1つも飛ばさない・表に無い段を言わない。**文と文の間だけでなく、1文の中でも**。「血が減ったから痛い」は酸素を飛ばしている）**⑧骨組みは1本の線**（寄せ方の骨組みの順を、前から後ろへ1度だけ進む。戻らない。段ごとに、その段の仕事だけ） | どの寄せ方・どの家族でも守る |
| **やわらかい（道具）** | 線の上の運び方（3段で死んでいく・たとえの未来・時間の巻き戻し…）・フックの形・たとえを入れるか・語り手・場面の数・長さの配分・締めの形 | 使うかどうかは、**この1本で一番伝わるか**で書き手が決める。使わなかった道具は、なぜ使わなかったかを1行書くだけでよい |

**一番大事な物差しは、売れるか（ROAS・購入÷クリック）。** 手を止めさせ、最後まで見させるのは、そのための入口。止まって、最後まで見られても、売れなかった広告がある（ワンドライのオリジナル09：維持率53%・CTR5.3%で ROAS 1.86）。

## 1. 書く前に、勝ち負けを見る（結果から学ぶ）

3. 「今回、勝ち筋のどれを引きつぐか／何を新しく試すか」を1行で決める

- 勝っていた書き出しの家族（同じ時期どうしで比べた物。確からしさ 中）：「悪いのは◯◯ではない」と打ち消す／お金で比べる／今の対策を名指しする／商品の名前から入る短い動画（49秒・92件）。**こわい結末だけで脅す書き出しは弱かった**（デス・アングルは、否定か体の中の出来事と組む。4-3）

### 2-2. 因果の鎖の表（本文を書く前に作る。固い⑦）
困り事の場面から、根本原因まで、そして解決策が効く所までを、**1段＝体の中の1つの出来事**で、上から下へ並べる。各段に、資料の出どころと、本文で言う文の番号を書く。置き場：作業のフォルダの `因果の鎖.md`。

| 段 | 何が起きる（体の中の出来事。1つ） | 資料の出どころ | 本文の文 |
|---|---|---|---|
| 1 | （場面の動作） | 理解シート B | |
| 2 | …… | H／I／B の番号 | |
| … | 根本原因の名前が付く段（「これが、◯◯です」） | H | |
| … | 放っておいた先（3段） | | |
| … | 解決策が効く所（押す → 皮ふの神経 → 血管が広がる → 下の層へ → ゆるむ） | I-3 | |

- **隣り合う2段の間を、初めて見た人が自分で埋められるか。** 埋められないなら、間の段を足す。「固まる」と「パンパンに張る」のように**状態の言葉が2つ**あるなら、その間に「縮んで固まった物を、前に曲げて無理に伸ばすから、張る」の段が要る。言えないなら、言葉を1つにする
- **原因の席には、体の中の出来事だけ。** 物・場所・時間（布団・寝具・冬・ゆうべ）は、鎖の「場面」の段には書けるが、「原因」とは言わない（責めている物の表にある物を原因にすると、字のとおりに読んでうそになる）
- **1文の中でも飛ばさない。** 「A だから C」の A と C は、表で隣り合う段。隣でなければ、B を同じ文か直前の文で言う。困り事（痛み）を何かのせいだと言う文は、痛みの直前の段（酸素が切れる）を先に言う。鎖の段を「〜した◯◯」の連体修飾で名詞に詰めない（動詞のある文で、起きた順に）。短くする事と、分かりやすくする事は別（`ZackDFilms寄り.md` 3-5）
- **否定する物は、この表より先に、相手から決まっている（理解シート C の1位）。表は、その物を段に使わずに組む。** 表の中にある物を否定すると、ロジックで「そのせいで固まる」と言う事になって矛盾する。だから、否定する物を段にしない（年・寒さ・体質は、段ではなく「輪が回りやすくなる条件」として記事へ）。きっかけ（場面の動作）は段1なので否定せず、相手がそれに付けている結論か場所を否定する（`ZackDFilms寄り.md` 4-4）。**表に無い物を、鎖の都合でさがして否定しない**（骨盤・マットレス：相手が思っていない物を否定しても、手が止まらない）。「〜だけではない」で逃げない
- 本文の文は、表の段の順で出す（段4のロジックの中では、表の順を入れかえない）。表の段を本文で飛ばした所・表に無い事を言った所は、正しさの確かめで×

## 3. 相手役の試写（分かりにくい所と「私の話か」と、鎖の抜けを見つける道具。売れるかの判定には使わない）
（2026-10-15 の較正：ワンドライで本当に売れた参考VSL10〈92件〉・17〈43件〉と、売れなかった01を、1人の相手役に見せたら、3本とも「流す・押さない」だった。1人の細い相手役は、売れるかを当てられない）
台本を知らない別のエージェントに、相手の行と台本の本文だけを渡して、なりきって読ませる（`templates/相手役の試写.md`）。
- **相手役は3人。** ①今回の相手 ②同じ商品を買った人の中で、別の困り事で一番多い人 ③冷めた人（困ってはいるが、広告がきらい）
- 見る所：分からなかった言葉・文（全部直す）／「私の話だ」と思った文（3人とも0なら、入口を考え直す）／流した文と訳（2人以上が同じ文で流したら直す）／**説明し返し**（3人が自分の言葉で言った「起きる訳」を 2-2 の表と並べ、抜けた段・入れかわった段を直す）／**「なんで、そうなるの？」の2文**（1人でもあれば、間の段が抜けている）
- **押す・押さないは、記録だけする。通る・通らないの線にしない**
- **つなぎ方の試写**（相手の理解シート C を決める時・確かめる時）：相手役に**場面（A・B）だけ**を渡して、何のせいだと思っているかを、その立場の5人に言わせる（`templates/相手役の試写.md`）。書き手が作った C・E・口ぐせを渡すと、相手役はそれを言い返すだけで、相手の理解の外れが見つからない（10 掃除機：書き手が口ぐせに「骨盤がゆがんでるのかな」と書き、相手役がそのまま「チラシが頭に浮かぶ」と答えた）
- 新しい試写のやり方を入れる時は、先に、売れた広告と売れなかった広告で試し、結果が成績と合うかを確かめる（較正）。記録：`~/.agents/skills/vsl-script/研究/試写の較正/`
- 試写の答えは `試写.md` に、そのまま残す

## しない事
- 決まりのファイルの段の順を、上から埋めていく書き方
- 「15の声を全部入れたから完成」と考える事（入れた上で、試写を通って完成）
- 試写で言われていないのに、決まりのために段を足す事
- 字数に収めるために、鎖の段を削る・名詞に詰める事（短くしただけで、分かりやすくはなっていない）
- 否定だけ言って、原因を言わない事（「〜のせいではありません」で止める）
- 鎖の中にある物を否定する事（「姿勢のせいではない」と言って、姿勢で固まる、と説明する）。「〜のせいだけではない」で逃げる事
- 鎖の表を作らずに本文を書く事。表に無い段を、本文で思いつきで足す事
- ロジックの段の途中に、場面・商品・気持ちを混ぜる事。結末や商品を言った後に、原因へ戻る事
