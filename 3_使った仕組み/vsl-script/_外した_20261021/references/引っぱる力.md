# 引っぱる力（最後まで見させる。どの型でも見る）

2026-10-08 に Seiyo が「めっちゃいい」と言った台本と、その次の「前の方が良かった」と言われた台本を比べて、差になっていた事。**並べる順の決まりではない**（順は型が決める）。書いた後に、この6つが台本の中にあるかを見る。無ければ、足す・直す。

## 1. 強い台本に共通していた事
| # | 事 | 中身 | 弱かった台本では |
|---|---|---|---|
| 1 | **見る人が「今、している事」が主役** | 見る人が毎日している事・していない事を、**動作で、短く、2〜3個**並べる。それが、困り事を悪くしている・放っている、と結ぶ。見る人は「見られていたのか」と思う | 主役が、ほかの人の言葉・事情・道具の話になっていた。見る人の動作が1つしか無かった |
| 2 | **書き出しの直後に、もう1発** | 書き出しの言い切りを、すぐ後の数文で、見る人の毎日につないで、もう1度強く言う（「その間ずっと、中では〜」）。書き出しを言いっぱなしにしない | 書き出しの後、すぐ別の説明に入っていた |
| 3 | **かたまりの終わりは、困り事の言葉か結末に戻る** | 説明のかたまり（3〜6文）ごとに、最後の文で、困り事の言葉（中身の質 2-1）か、こわい結末に戻る。何度も同じ言葉に着地するので、頭に残る | かたまりが、説明のまま終わっていた |
| 4 | **原因が早い** | 原因の1文が、全体の4分の1までに出る | 前置きの説明が長く、原因が後ろにずれた |

**寄せ方が運びを決める時（スケルトン・クレイ物語・権威実写）**（2026-10-11。別の商品で試して、4 と 1 を当てるかが決まらなかった）：4 の「4分の1まで」は外れ、寄せ方の数にする（`SKILL.md` 5b の表）。1 は外れない（材料は、相手が今している事）。ただし、置く所と数は、寄せ方の運びに合わせる。2・3・5・6 は、そのまま見る

## 2. 「この先も見たい」があるか（2026-10-08 Seiyo）
台本を4つに割る（4分の1ごと）。**それぞれの区切りの所に、次を見たくなる理由があるか**を見る。
| 次を見たくなる理由の種類 | 中身 |
|---|---|
| まだ答えていない問い | 「では、なぜ〜なのか」を、見る人の頭に残したまま進む（答えは少し後） |
| こわさの後の救い | こわい結末を言った直後に、道がある事を一言（「でも、まだ間に合います」の類）。答えは、まだ言わない |
| 逆を言う | 「〜だと思いますよね。逆です」。理由は次で |
| 数える | 「理由は2つあります」「あと1つ」 |
| 自分に当てる | 「あなたの◯◯でも、今、同じ事が起きています」 |
| 先に見せる | 後で言う大事な事を、一言だけ先に（「これを止める方法は、1つだけです」） |

- **毎回、同じ物を使わない。同じ文も使わない。** 区切りごとに、ちがう種類を使う。台帳の直前の台本と、同じ種類ばかりにしない
- 区切りに理由が無い所だけ、1文足す。**全部の区切りに無理に入れない**（入れすぎると、あおりに聞こえる）。4つのうち2つ以上あればよい
- 足した文が、本文の線から外れていないか（言ったのに、後で答えていない、は一番だめ）

## 2-2. 同じ事を、2回言っていないか（2026-10-09 Seiyo「重複している」）
- **1つの事は、1か所で言う。** とくに重なりやすいのは：見る人が流している・信じている理由（否定する物）／「そのままにしている」「待っている」という今の態度／結末の言い切り。言い方を変えても、同じ事なら重複
- 1 の「書き出しの直後に、もう1発」は、**言い直しではない。** 書き出しに無かった事（見る人の毎日の動作・今この時の事）を足して強くする。同じ中身をもう1度言うだけなら、要らない
- 見つけ方：台本の文を1つずつ、「この文は、何を言っているか」を3〜5文字で横に書く。同じ札が2つ付いたら、強い方を残して、もう1つを消す（結末を段を上げて言う所・かたまりの終わりで困り事の言葉に戻る所は、重複に数えない）
