# 型の選び方

**型**＝見せ方の器（だれが話すか・どの順で運ぶか・何で引っぱるか）。型の棚は `型/`（1つ1ファイル）。段階の芯（通る点）は、どの型でも同じ。

## 1. 選び方
| 場面 | する事 |
|---|---|
| 型を指定された（「◯◯が話している系で」「◯◯みたいな感じで」） | その型のファイルで書く。棚に無い型なら、`型/新しい型の作り方.md` で、その場で型を作って書く |
| 「◯◯と同じ型で」と言われた | 商品の `06_原稿/台本の台帳.md` で、その台本の型を引いて、同じ型で書く。中身（書き出し・否定する物・場面）は変える |
| 指定が無い・成績がまだ無い | 台帳の**直前の台本と違う型**にする。**3本に1本は、棚に無い新しい型**（`毎回変える物.md` の 3）。棚から、まだ使っていない型・使った回数の少ない型を3つ取り、**企画を1行ずつ3つ**書く（型＋書き出しの方向＋何で引っぱるか）。その相手が一番「え？」となる物を1つ選ぶ。棚の型がどれも合わなければ、新しい型を作ってよい |
| 勝っている型がある（台帳の判定が「勝ち」） | 何本か頼まれたら、3本のうち2本は勝っている型で中身を変え、1本は新しい型・使っていない型 |
| 負けが続いた型（判定「負け」が2本） | 棚には残す。指定された時だけ使う |

- 1度に何本か書く時は、**全部ちがう型**にする（勝っている型を続ける時を除く）
- 型のファイルの「長さ」（◯〜◯文）は目安。「中身の質」の決まり（1文に1つ・困り事に結ぶ）とぶつかったら、中身の質が勝つ。運ぶ順と、どこを一番厚くするかは守る
- 型のファイルの「向く段階」に今回の段階が無い型は、選ばない。運ぶ順の表が今回の段階と合わない所は、**段階の芯が勝つ**（通る点・厚くする所・商品を出す時は、芯のとおり）
- 面白さは、型と中身の組み合わせで作る。同じ型でも、書き出しの向き・否定する物・場面を変える

## 2. 台帳（商品ごと）
`<商品のフォルダ>/06_原稿/台本の台帳.md`。1行が1本。無ければ、下の頭で作る。
```
| 日付 | 台本（置き場所） | 段階 | 相手 | 型 | 書き出し（全文） | こわさの種類・着地の言葉 | 書き出しの向き | 道具 | 広告の番号 | 成績（3秒見た割合／ROAS） | 判定 |
```
- 台本を出したら、1行足す（成績と判定は空）
- **台帳が無い時（2026-10-11。別の商品で試して、「直前の2本・3本と比べる」が出来なかった）**：上の頭で作る。前に書いた台本は、「使った物の記録」から分かる分だけ、古い順に行にする（分からない欄は空。作らない）。記録も無ければ、今回の1本が1行目で、「直前と変える」決まりは、当てる物が無い（書き出しは、軸の種類で書く）
- **商品のフォルダを書きかえない、と言われて書く時**（人に書かせる時など）：台帳も記録も、作らない・足さない。出力の一番下に「台帳に足す1行」を、そのまま貼れる形で書く（`templates/出力の形.md`）。足すのは、頼んだ側
- 成績と判定は、Seiyo が言った時・ダッシュボードの数字を渡された時に入れる。**自分で勝ち負けを決めない**
- 書き出しの替え（フックだけを変えたテスト）を出した時は、替えごとに1行足す（台本の欄に「◯◯の書き出しちがい」と書く）
- 判定の基準：書き出しは「3秒見た割合」、台本全体は「ROAS」（2026-10-08 の案。Seiyo が変えたら、それに合わせる）

## 3. 型を棚に足す時
新しい型で書いた台本に、Seiyo が OK を出したら、`型/` にファイルを足す（`新しい型の作り方.md` の形）。見本の置き場所に、その台本を書く。
