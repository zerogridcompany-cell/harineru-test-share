## 核1. 答えは、隠して、積んで、最後に明かす
見る人は、答えを知ったら見るのをやめる。答えだけを先に聞いても、なぜそうなのかが分からないので、自分の事として刺さらない。
1. **書き出し（フック）で言ってよいのは、次の4つだけ。** ①相手の思いこみ・口ぐせ・している事 ②それが外れている事（「その◯◯の原因は、◯◯ではありません」）③放っておいた先 ④答えたくなる問い（「〜すると、どうなるのか」）。**本当の原因の場所・名前・仕組みは言わない**
2. **本当の原因を初めて言うのは、鎖（核2）を積み終えた所。** 形は「この（鎖の最後の出来事）が、あなたの（相手の困り事の言葉）の正体です」（2026-10-21 Seiyo「このパンパンが、夕方の足のむくみの正体です、の方」）。鎖の行き着いた所に、相手がふだん使う困り事の名前を結ぶ。原因の始まり（鎖の1歩目）を言い直さない。書き出しの「◯◯ではない」も繰り返さない（4）。確かめ：明かす文だけを読んで「私のあれの事か」と分かるか。それより前に、□□を名前で言わない
3. 順は：思いこみ → 外れている（1回だけ） → 「じゃあ何？」を開けたまま鎖 → 本当の原因は□□ → 放っておいた先 → 今なら間に合う訳 → することは1つ → 商品
4. **「外れている」と「本当は何か」は、別の事を1回ずつ言う。** 「◯◯ではありません」は台本の中で1回だけ。明かす文では、もう「◯◯ではなく」と繰り返さず、本当の原因の名前と場所だけを言う（例の形：書き出しで「その痛みの元は、目ではありません」と言ったら、明かす文は「その元が、首の付け根の奥の、小さな筋肉です」）
5. **書き出しで開けた問いに、明かす文がそのまま答える。** 書き出しが「家では平気なのに、職場では痛い」なら、明かす文か、その直前の歩が「だから、職場でだけ痛む」に答えている。答えが台本の別の所に散らばっていない
6. **打ち消すのは、台本の中で先に出した思いこみだけ。** 「あなたの◯◯のせいでもなかった」の◯◯は、書き出しか場面で、相手の言葉として先に出した物だけ。出していない物（年・体質など）を、ここで初めて打ち消さない
7. **確かめ：** 書き出しの文だけを、台本を知らない人に読ませて「本当の原因はどこだと思う？」と聞く。言い当てられたら、書き出しが答えを言っている。書き直す

## 核2. 鎖は「すると → だから」で1歩ずつ進む
説明は、「何がどうなって、次に何が起きるか」が見える1本の鎖にする。
1. **1文に1歩。** 文の主語は、前の文で起きた事（または、その物）。述語は、その結果、次に起きる事を1つ
2. **前の文の物は、名詞を付けた指す言葉で受けてよい（むしろ受ける）：** 「この姿勢は」「その筋肉は」「このにおいは」。つながりが見える。**名詞の無い「それ」「そこ」「これ」だけで物や場所を指さない**
3. **程度・位置・状態の言葉には、比べる相手を付ける：** 「少し前」→「ふつうの◯◯より少し前」、「硬い」→「ゆるんでいる時より硬い」、「多い」→「ふだんの何倍」。比べる相手が無いと、見る人は何と比べてか分からない
4. **状態を言ったら、まず「それがどういう状態か」を見える形で言い直し、次の文で、その状態が何を起こすかを言う：** 「この◯◯は、△△と□□のあいだが詰まり、そこにある◯◯が縮んだままになる◯◯です」→「縮んだままの◯◯は、◯◯を押します」
5. **鎖は、相手の困り事に届く一番短い道で、4〜6歩。** 困り事に1歩も近づかない段（名前の説明・役目の説明・細かい作り・へえの寄り道）は、鎖に入れない。記事に回す
6. **鎖の最後の歩は、相手の困り事の言葉で着く**（「…すると、目の奥が痛いと感じる」「…すると、また同じ床でする」「…すると、朝いちばんに腰が痛む」）。その次の文が核1の2（本当の原因の名前）
7. **確かめ（すると・だから読み）：** 鎖の各文の頭に「すると」か「だから」を付けて、声に出して読む。付けて読めない文は、鎖の歩ではない（外すか、記事へ）。また、台本を知らない人に鎖だけを読ませ、「AだからB、BだからC」と1回で言い返させる。詰まった所は、文を足さずに言い換える。どうしても足すなら、別の1歩を消す（歩の数を増やさない）
8. **歩の数え方：** 新しい出来事が1つ起きる文だけを1歩と数える。前の歩を言い直す文は歩ではなく、入れない（言い直さないと分からない時は、前の歩の文の言い方を直す）。日本語の検品で1文を2つに分けた時は、2文で1歩と数える
9. **「だから」は、前の文が本当に理由の時だけ**（核2b）。明かす文の頭に、決まった言葉として「だから」を付けない

例の形（3つの世界。写さない。形だけ見る）
| 世界 | すると → だから の鎖 |
|---|---|
| 体 | ◯◯をしている時、頭は、ふつうの姿勢より前に出る → この姿勢だと、◯◯と◯◯のあいだが詰まる → 詰まった所にある小さな筋肉は、縮んだまま固まる → 固まった筋肉は、すぐ上の神経を押す → すると、押された神経の痛みを、◯◯の痛みのように感じる → その元が、この筋肉 |
| 物 | ◯◯を拭くと、上の汚れは消える → でも、継ぎ目の中に入った分は残る → 残った分を、菌がにおいの元に変える → このにおいは、拭くたびに少しずつ重なる → すると、拭いても、くさいまま → その元が、継ぎ目の中のにおいの重なり |
| 生き物 | 犬は、する場所を、目ではなく鼻で決める → 鼻が探すのは、前にしたにおい → 新しいシーツには、そのにおいが無い → においが残っているのは、前にした床だけ → すると、シーツの横の床でする → その元が、床に残ったにおい |

## 核2b. つなぎの言葉は、前の文との関係が本当にその言葉の時だけ
「だから」は前の文が理由の時、「すると」は前の文の次に起きる時、「でも」は前の文と逆の時だけ使う。1つずつ、前の文と並べて「AだからB」と声に出し、意味が通るかを見る。通らないなら、つなぎの言葉を外すか、文を直す。別の1人（決まりも商品も知らない読み手）に、つなぎの言葉ごとに「前の文とこの言葉でつながるか」を聞く（`templates/相手役の試写.md` の意味の検品）

## 核8. シンプル（1本で言う事を増やさない）
1. **1本で言うのは、思いこみ1つ・本当の原因1つ・放っておいた先1つ・する事1つ。** それぞれを、名前1つ・絵1つで言う。2つ目の原因・2つ目の結末・名前の説明（「専門的には」）・作りの細部は入れない（記事へ）
2. **段を並べない。** 「1段目は…、2段目は…、3段目は…」と何段も並べない。放っておいた先は、「今はこう → このままだと、こうなる」の2点で言う。どうしても段で言う時は、ふつうの言い方（「1段階目」）で、今の段と最後の段の2つだけ
3. **1文に新しい事は1つ。** 1文の中で、新しい名前と新しい出来事を同時に出さない
4. **言葉は、ふつうの人が口で言う言い方。** 数え方・言い回しが、話し言葉として自然か（「3段目」ではなく「3段階目」、の類）。迷ったら、相手が友だちに話す時の言い方にする
5. **確かめ：** 台本を読んだ人に「この動画は何を言っていた？」と聞き、3文以内で「◯◯だと思っていたけど、本当は△△。このままだと□□。だから◇◇をする」と言えるか。4つより多い事を言われたら、入れすぎ

## 核10. 言葉足らずを残さない（2026-10-21 Seiyo「文章構成は良くなったから、もっと言葉足らずを減らして」）
1文を切り取って聞いた時に、「何を？」「どこへ？」「いつ？」「何の？」と聞き返せる所を残さない。鎖の歩は増やさず、文の中の言葉で埋める。
1. 動詞には、目的語を付ける（「切って、洗って」→「野菜を切って、お皿を洗って」の類）
2. 「上へ・外へ・奥へ・中へ」には、行き先の名前を付ける（「上へ」→「心臓のある上の方へ」の類）
3. 物には、何の物かを付ける（「跡」→「ゴムの跡」の類）
4. 省いた言い方は、いつ・何がを言う（「出たり引いたり」→「夕方に出て、朝には引く」の類）
5. 相手が知らない体・物・生き物の働きを鎖で使う時は、初めて使う所で1回だけ、何のための働きかを1文で言う（新しく足してよい文は、これだけ）
6. 行き先・見せる物は名前で言う（「記事に」→「下の記事に」）
7. 確かめ（聞き返しの検品）：台本を知らない1人に、1文ずつ読ませ、聞き返したい事を全部書き出させる。出た物は全部埋める

## 核3. 相手の頭の中から組む
文は、相手が今思っている事を、1歩ずつ動かすためにだけ書く（`相手を1人に決める.md` 0章の理解シート・`中身の質` 2-6）。否定する物は、相手の理解シートの「何のせいだと思っているか」の1位（`寄せ方/ZackDFilms寄り.md` 4-4 の箱ア・イ・ウの考え方は、どの寄せ方でも使う）。きっかけ（場面の動作）は鎖の1歩目なので否定しない。

## 核4. 強さ
（ほかのファイルの「うそだ・言いすぎが2人以上なら使わない」「相手①がうそだと言った物は落とす」は、全部この核4に従う＝記録だけ）
書き出しと「放っておいた先」は、一番強い言葉で言い切る（`中身の質` 4-1・5）。試写の「言いすぎ・脅し・うそだ」は記録だけで、それを理由に弱めない。落とすのは、相手が「分からない」「私の話ではない」「そんな事は思っていない」と言った物だけ。

## 核5. 15の心の声
受け持ちの声は全部入れる（`15の心の声.md`・`記事と分ける.md`）。声のために段を足さない。①「あなたのせいではない」は、本当の原因を明かす文の直後に置くと、説明ではなく種明かしになる。打ち消すのは、先に出した思いこみだけ（核1の6）。

## 核6. 日本語
1文ずつ、主語（だれが・何が）と、並べている物の形と、対比の前後の動詞を見る（`寄せ方/ZackDFilms寄り.md` 3-6 の4つの形）。意味が1つに決まらない動詞（戻る・変わる・効く・届く・抜ける）は、何が・何に・どこへ、を同じ文に置く。

## 核7. 商品の資料の「決まった言い方」より、核が先
商品の `05_原稿の決まり.md` が、原因の名前の説明などの言い方を決めていても、動画では名前だけを言い、説明は記事へ回す（核2 の5）。決まった言い方は、記事で使う。
