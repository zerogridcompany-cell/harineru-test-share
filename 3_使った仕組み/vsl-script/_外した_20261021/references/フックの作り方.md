## 1. フックは2つの軸でできている
**入り方（どう始めるか）× こわさ（何で止めるか）。** 同じ入り方でもこわさを変えれば別のフックになり、同じこわさでも入り方を変えれば別のフックになる。

### こわさ（何で止めるか。前の 4-1b の A〜H をそのまま使う）
A その場所がどうなるか／B もう始まっている／C 逆さ／D 時間（今だけ）／E 失う物／F 知らなかった事実／G 大きさ／H 答えられない問い。強さは下げない（`核の決まり` 核4）。「死ぬ・こわれる・戻らなくなる」の級を、ためらわずに使う。

## 2. 全部のフックが通る物差し（どの家族でも同じ）
1. **答えを言っていない**（核1の1）。本当の原因の場所・名前・仕組みが入っていない。入り方4（外れている）でも、「何ではないか」までで止める
2. **だれの話か、1秒で分かる。** 相手の場面か口ぐせの言葉が入っている（理解シートの件数の多い物）
3. **デス・アングルが必ず入っている（2026-10-21 Seiyo「フックは、もうデス。できる限りデス・アングルに近づけて。夕方足が痛い、このままではこうなってしまう、みたいな」。前の版で「やばいは必須でない」とゆるめたのは取り消し）。** 形は「場面か症状 → このままだと、こうなる（死ぬ・こわれる・戻らなくなる級）」。どの入り方の家族でも、このデスを入れる（問いの形なら「このまま放っておくと、その◯◯は、どうなるのでしょうか」）。本文の書き出しの既定は「場面＋デス」。1文目だけの試写で、相手①が「やばい」と思わなかった物は使わない。観察だけ・豆知識だけで終わっていない
4. **続きを見ないと閉じない問いが1つ開いている。** 2つ以上開けない
5. **一息で言える。** 2文まで・合わせて60字まで（声に出す字）
6. **次の文にまっすぐつながる。** 2文目以降の場面・鎖が、フックで開けた問いに答えに行く
