# 段階④ 商品を知っている人への台本 — 芯

**相手**：この種類の商品がある事も、何をする物かも知っている。見た事がある・気になっている・似た安い物と比べている・前に似た物を買って合わなかった、のどれか。買っていないのは、疑いか迷いが1つ残っているから。
**頭の中**：「本当に効くん？」「どれも同じちゃうの」「高くない？」「私に続けられる？」。
**動かす一歩**：「迷っていた理由は、消えた」。
**書く相手は、この段階の中の1人**（人物メモ）。

ここが決めるのは、どの型で書いても通る点だけ。並べる順・だれが話すか・何で引っぱるかは、型（`型/`）が決める。

## 1. 通る点（7つ）
| # | 見る人の頭の中 | 中身 |
|---|---|---|
| 1 | 「それ、気になってた」 | 人物メモの**疑い・迷いを、その人の言葉のまま、先に口に出す**。商品の種類の名前を、1文目から言う。その上で、強く言い切る（疑いは半分正しい・選び方をまちがえると損をする・迷っている間に進む、のどれか） |
| 2 | 「疑うのは、まちがっていなかった」 | 疑う理由を認める。似た物で上手くいかない事には、理由がある、と言う |
| 3 | 「見る所は、そこだったのか」 | **3 と 4 を合わせて、全体の半分（ここが、この段階の中心）。** この種類の商品を選ぶ時に、見るべき所を1つか2つ（違いの物差し）。なぜそこで差が出るのかを、作りから。原因の説明は、物差しに要る分だけ（3文まで） |
| 4 | 「これは、そこを満たしている」 | 商品が、その物差しをどう満たしているか。**材料にある事実だけ**（形・作り・付く物・使い方）。商品の名前は、最初の4分の1までに出す |
| 5 | 「私でも使える」 | 使う場面（いつ・どこで・どのくらい）。使った時の感じ。1で出した疑い・心配に、1つずつ答える |
| 6 | 「値段は、そういう事か」 | 値段を言うなら、何と比べるかを決めて言う（今かかっている物・続けた時の物。**材料にある数だけ**）。値段を言わない時は、この点は飛ばしてよい |
| 7 | 「今、決めよう」 | 最後の姿 → 締め（この段階が一番強く。迷っている間にどうなるかを一言足してよい） |

## 2. 段階④の決まり
- **問題・原因の説明は、合わせて3文まで。** この人は、もう知っている（結末を言う文は数えない。中身の質 2-2 の「3〜4歩」・引っぱる力の「直後にもう1発」より、この決まりが勝つ）
- 相手は、困り事の場面ではなく、**疑い・迷いで決める**（記録と重ならないようにするのも、疑いの方）
- 「商品の種類の名前」＝だれでも知っている呼び方。「商品の名前」＝その商品の呼び名・ブランド。種類の名前と呼び名が同じ商品では、ブランドの名前で分ける
- 物差し（3）は、材料にある「自社の強み」「設計の理由」から取る。**寸法・本数・ほかの物との数の差は、材料に数が無ければ言わない**（形・考え方で言う）
- 1の疑いは、材料の「買う時の壁」と、同じ種類の商品を使った人の言葉から取る。自分で作らない
- **ほかの売り手の名前を出さない。** 種類で言う（安い物・似た形の物）
- **中身の質 4-1（書き出しの「やばい」）は、この段階では「損」と「手おくれ」で言ってよい**（まちがった方を選ぶ・迷っている間に進む）。ただし、困り事の起きている所の結末につなげる
- 人物メモの中心は、**何を疑っているか・何と比べているか・前に何で失敗したか**
- 長さ：指定が無ければ 700〜900字（4つの段階で一番短い）
