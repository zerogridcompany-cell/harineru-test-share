# 段階② 問題に気づいている人への台本 — 芯

**相手**：困り事を毎日感じている。いつ・どんな時に困るかは、本人が一番よく知っている。でも、**なぜそうなるのかを知らない**。たいてい、まちがった物のせいにしている（生まれつき・年・くせ・育ち・「そのうち良くなる」など）。対策は、まだ本気で探していない。
**頭の中の問い**：「なんで、こうなるんやろ」「これ、良くなるんかな」「このままで大丈夫かな」。
**書く相手は、この段階の中の1人**（人物メモ）。段階の全員に書かない。
**動かす一歩**：「原因はそこだったのか」。

ここが決めるのは、**どの型で書いても通る点**だけ。並べる順・だれが話すか・何で引っぱるかは、型（`型/`）が決める。

## 1. 通る点（6つ。どの型でも、全部通る）
| # | 見る人の頭の中 | 中身 |
|---|---|---|
| 1 | 「私の事だ」 | 人物メモの**困り事の場面**（いつ・何をしている時に・どうなるか）か、その時の本人の言葉。1文目で、その時の感じを思い出す。対策の名前・商品・事情だけでは取らない |
| 2 | 「原因は、それだったのか」 | **原因を、先に1文で言い切る**（「その（困り事の言葉）の原因は、◯◯の△△です」の形。中身の質 2-2）。その後、3〜4歩で説明する。困り事の原因を、**見えない所にある具体的な物の、具体的な状態**で1つ言う。なぜそうなると困り事が起きるのかを、作りから教える。**ここが一番厚い（全体の3〜4割。原因の1文・3〜4歩・積み上げの橋の文・型が言う原因まわりの部分を合わせて数える。歩を増やして厚くしない）** |
| 3 | 「このままだと、やばい」 | 放っておくと、**その場所そのものが、どうなるか**（こわれる級の結末。中身の質 4-1）。書き出しで言った結末に、ここで着く。原因の説明と同じ線の上で言う（別の話を持ってこない） |
| 4 | 「だから、これが要るのか」 | 原因を解くのに要る事を1つ。今の暮らし・今している事では、なぜそれが起きないか |
| 5 | 「これなら、それが出来る」 | 商品が、4をどうやってするか。使うと、見えない所で何が起きるか（3の逆）。**商品の名前は、2が終わるまで出さない** |
| 6 | 「見てみよう」 | 取り戻した姿 → 締め（中身の質の「最後の姿」「締め」） |

## 2. 段階②の決まり
- 否定する物は1つ。人物メモの「何のせいだと思っているか」。その人が口にしている言葉で言う
- 対策（買った物でも、自己流の手当てでも）を主役の敵にしない（それは段階③）。**対策の比べ合いをしない**
- 2 が薄く、すぐ商品に行く台本は、段階②の仕事をしていない
- 長さ：指定が無ければ 800〜1,000字（声で2分〜2分半）
