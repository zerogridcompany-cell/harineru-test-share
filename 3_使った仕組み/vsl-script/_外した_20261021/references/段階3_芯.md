# 段階③ 解決策を知っている人への台本 — 芯

**相手**：何かをして、効かなかった人。買った物・通った所・自己流の手当てのどれかを、今も続けているか、あきらめかけている。原因らしき物は聞いた事がある。
**頭の中**：「これだけやっているのに、なんで良くならへんの」「私のやり方が悪いんかな」。
**動かす一歩**：「今の対策には、これが足りなかったのか」。
**書く相手は、この段階の中の1人**（人物メモ）。

ここが決めるのは、どの型で書いても通る点だけ。並べる順・だれが話すか・何で引っぱるかは、型（`型/`）が決める。

## 1. 通る点（8つ）
| # | 見る人の頭の中 | 中身 |
|---|---|---|
| 1 | 「私が使っている、それの事だ」 | **今している対策を名指し**して、強い結末で言い切る。その対策を使っている人が、1文目で分かる |
| 2 | 「見られていた」 | その対策の中で、その人がしてきた事（替えた・増やした・重ねた・通い直した）を、動作で。がんばってきた事として書く（責めない） |
| 3 | 「悪いのは、私の使い方ではなかった」 | その対策が**している事**を、まっすぐ言う（どこまでは効くか。うそを言わない）。その上で、「でも、この（困り事の言葉）には」と強く否定する |
| 4 | 「原因は、そこか」（短く） | 原因を1文で言い切り、3歩まで。**足りない物が、なぜ要るのかに着く分だけ** |
| 5 | 「これが、足りなかったのか」 | **5 と 7 を合わせて、全体の半分（ここが、この段階の中心）。** 今の対策に欠けていて、商品が持っている物を1つか2つ。**形のある言葉で**（広さ・深さ・回数・届く場所・力 など。形の無い言葉にしない）。今の対策の形・使い方から、なぜそれが足りないかを説明する。続けた先（お金・時間・見えない所）を1つ |
| 6 | 「替えればいいのか」 | 足りない物を持つ物として、商品を出す。**商品の名前は、全体の真ん中までに出す**。今の対策をしていた、同じ時・同じ場所で、代わりに使う絵 |
| 7 | 「これなら、足りる」 | 足りない物の言葉をもう一度使って、商品がどう満たすか。使った時の感じ。今の対策と比べて、要らなくなる事（買い足す・予約する・だれかに頼む） |
| 8 | 「見てみよう」 | 最後の姿（**今の対策が要らなくなった毎日**）→ 締め |

## 2. 段階③の決まり
- **敵は1つ。** 1で名指しした対策を、最後まで変えない・増やさない。ほかの対策の名前を出さない
- 3で、対策が効く所は認める（全部だめだと言うと、使っている人は信じない）
- 5 の中の「続けた先」は、4（原因）のすぐ後に置いてもよい。商品の名前を真ん中までに出すために、5 の説明の一部を名前の後（7）に回してよい
- 原因の説明を長くしない（長くなると、段階②の台本になる）。4は、5より短く
- 5で、**その対策の形から**説明する（どの対策にも言える否定にしない）
- 5 の「形のある言葉」は、体でない困り事の時も同じ（大きさ・形・置く所・続く時間・手間の数 など。2026-10-11。体の例だけでは、別の商品で言葉が出なかった）
- 人物メモの中心は、**何を・どのくらい・どうやって試して、どうだったか**と、その時の気持ち
- 長さ：指定が無ければ 900〜1,100字
