# 勝ち負けから分かる事（ワンドライの動画広告・2026-10-15時点）

結論から書きます。**売れるかどうかは、フック率でも維持率でもリンクCTRでもなく、クリックの後（CVR）で決まっていました。** 書き出しの強さで勝っても、記事や商品ページで「動画が約束した事」が続かないと売れません。新ハーネスの台本（新A-2）は、フック率・維持率・CTRがどれも過去最高なのに、ROAS は 1.62 でした。台本は「止める・見させる・押させる」の力では、もう勝っています。次に詰める所は、クリックの後の約束を合わせる事です。

元の数字は `台本と数字の台帳.md`（1広告＝1行、全99本）、集計の生の出力は `tools/data/集計.md` にあります。

## 数字の前提

- **対象**：ワンドライのキャンペーン（名前が「WD｜」か「ワンドライ｜」で始まる物）のうち、動画の広告99本です。素材（同じ動画）でまとめると65本になります。静止画は入れていません。韓国の配信（4本）は、集計からは外しました。
- **期間**：配信を始めた2026-09-05から10-15まで、全期間の合計です。Meta の数字は 10-15 18:29 に読み取りだけで取りました。購入は Meta の計測なので、Shopify の注文数とは一致しません。
- **足切り**：素材ごとの合計消化が **40,000円以上の23素材**だけで比べました。全体の CPA は約8,800円なので、40,000円で期待できる購入は4〜5件です。購入の数は偶然で ±2件くらいは平気でぶれます（ポアソン分布＝まれな出来事の数のぶれ方）。なので、**1素材の購入が10件を切る差は「傾向」までにしか使えません**。
- **損益分岐**：ROAS 1.49。守るラインは 2.0 です（`newec_harness/ワンドライ/02_損益分岐.md`）。
- **一番大きな落とし穴（時期）**：口座全体の ROAS は時期とともに落ちています。作った時期ごとに分けると、9/5〜14 が 3.49、9/15〜25 が 2.94、9/26〜10/9 が 1.73、10/10〜 が 1.14 です。早く出した素材ほど数字が良く見えます。なので、なるべく**同じキャンペーンの中、同じ時期どうし**で比べました。下の確からしさも、そのつもりで付けています。

## 分かった事（確からしい順）

**1．フック率と CTR を見ても、売れるかは分からない（確からしさ：高）**
23素材で、ROAS と各数字の順位がどれだけそろうかを見ました（スピアマンの順位相関 ρ。1 ならぴったり同じ順、0 なら関係なし）。フック率は ρ＝0.01、リンクCTR は −0.07、維持率は −0.45 でした。関係があったのは CVR（購入÷LPV）だけで、ρ＝0.70 です。目立つ例を2つ挙げます。オリジナル09（322秒）は CTR 5.30%・維持率 53% と強く、Meta が 678,517円も回しました。それでも CVR 0.7%、ROAS 1.86 です。新A-2 は CTR 7.34% で全素材の1位でしたが、購入は 5件（ROAS 1.62）でした。
→ 書き出しを3秒再生率で選ぶのはよい。ただし「3秒再生率が高い＝勝ち台本」とは扱わない。

**2．同じ動画でも、飛び先を「-new」の記事に替えると、6組中5組で ROAS が落ちた（確からしさ：中）**
- 参考VSL29：記事02 は ROAS 3.01（86件）、記事02-new は 1.48（12件）
- 参考VSL36：記事04 は 3.72（20件）、04-new は 1.07（5件）
- オリジナル09：記事04 は 2.60（34件）、04-new は 0.52（3件）
- オリジナル06：記事02 は 4.47（22件）、02-new は 1.88（1件）
- オリジナル11：記事04 は 4.72（12件）、04-new と組んだ物は 2.08（7件）

逆に上がったのは参考VSL39 の1組だけです（2.40→2.53）。ただ、-new の記事は口座全体が落ちていった9/27以降に出ています。なので、記事のせいか時期のせいかは、ここだけでは分けられません。同じ日に2つの記事へ半分ずつ流すテストをすれば、白黒が付きます。

**3．最初の大きなテスト（同じ時期・同じ CBO）で勝ったのは、短くて、早めに商品・お金・比較を出す動画（確からしさ：中）**
「VSL初回テスト｜CBO 15,000円/日」の中だけで比べました。
- 参考VSL10（49秒）：書き出しが「ワンドライは〜トイレシーツです」と商品の名前から。461,126円・92件・ROAS 3.60
- 参考VSL11（50秒）：「2枚のシーツ。一方は毎年約6万円…」とお金で比べる。358,804円・73件・4.05
- 参考VSL17（128秒）：「多くの飼い主がやっている、かえって悪化させる3つの事」と今の対策を名指し。223,645円・43件・3.98

同じ時期の自作アニメ2本は数字が下でした。オリジナル03（「朝、犬のおしっこを踏んだ事ありませんか」）が 2.79、オリジナル02（「何度教えてもシーツのすぐ横で」）が 2.27 です。長さで全部をまとめると、70秒以下が ROAS 3.22（CPA 6,571円）、131秒以上が 2.24（CPA 13,328円）でした。ただし短い物は早い時期に出て、商品ページに飛んでいます。時期と飛び先の差が混ざっています。

**4．「悪いのは犬ではない」と打ち消す書き出しは、時期をまたいで強い（確からしさ：中）**
参考VSL29（「愛犬が家の中でおしっこをするのは、悪い子だからではありません」）は、一番お金が回った素材です。1,071,755円・99件・ROAS 2.61（日本のみ）でした。1本約20,000円ずつ同じ額を入れた ABO テスト（9/28〜）でも、同じ書き出しの自作が上位に来ました。オリジナル14（「叱るほど隠れてするようになる。悪いのは愛犬ではありません」）が5件・ROAS 9.40、オリジナル15（「頑固だからでも、頭が悪いからでもありません」）が5件・7.52 です。同じテストの他の10本は0〜2件でした。ただし、オリジナル14 は本番の CBO では 53,593円で1件（0.50）です。1本ごとの差は小さい数の話なので、「この書き出しの家族は外しにくい」くらいに読んでください。

**5．専門家・施設の話から入る物は、悪くない（確からしさ：低〜中）**
「ある獣医師が見続けていました」から入るオリジナル06 は、225秒と長いのに ROAS 4.13（23件）でした。「うちには毎週40頭がやってきます」の参考VSL32 は 2.78（24件）です。この型を合わせると、ROAS 3.26・CPA 7,651円で、型別では上の方に入りました。

**6．負けた書き出し（確からしさ：低〜中。どれも購入が少ない）**
- 返金の寸劇（参考VSL33）：74,393円・2件・ROAS 0.30
- 「外でだけトイレをする子犬に育てたいですか」（参考VSL37・①）：44,278円・1件・0.88
- 「これは良い、これは悪い」の健康比較（参考VSL40）：27,341円・0件
- 「今すぐやめてください。尿路結石になります」（オリジナル07）：26,777円・1件・1.45
- 自作の「今の対策を名指し」（オリジナル17）：23,544円・0件

オリジナル17 は、フック率が 36% と低い物でした。ABO テストでフック率 36% だった2本（オリジナル16・17）は、購入が2件と0件です。フック率が低すぎる物は、やはり負けます（下限の足切りとしては使える）。

**7．新ハーネス（vsl-script）の9本は、まだ判定できない（確からしさ：判定不能）**
9本とも10/12作成で、10/10以降の口座全体が ROAS 1.14 の時期に出ています。40,000円を超えたのは新A-2（権威実写・163秒）だけでした。新A-2 はフック率 59.0%、維持率 60.1%、CTR 7.34% で、上の方の数字はどれも過去の全素材を上回ります。ただ、購入は 79,720円で5件（ROAS 1.62）です。他の8本は 600〜7,800円しか回っておらず、0件でも何も言えません。

もう1つ注意があります。飛び先の vercel.app の記事は、**リンククリック713に対して LPV が85**しか数えられていません。ページが開かれる前に帰っているのか、計測のタグが LPV を拾っていないのかの、どちらかです。CVR 5.9% は見かけの数字で、購入÷クリックで見ると 0.7% でした。

## これを最新に保つ方法

1. 数字を取り直して台帳を書き直します。Meta は読み取りだけで、設定は一切変えません。
   `cd /Users/seiyo/.agents/skills/vsl-script/研究/結果/tools && ~/.agents/skills/_env/venv/bin/python update_ledger.py`
   新しく出した動画は、手元の納品動画から最初の10秒を自動で文字起こしします（1本2〜3秒。済んだ物は `tools/hooks.json` に残るので2回目からは飛ばす）。数が多い時は `--top 30` を付けると、消化の大きい30素材までにできます。
2. 新しい素材を出したら、`tools/対応表.json` に1行足します（見た目の型・段階・アングル・書き出しの種類）。足さないと「未記入」と出ます。広告名に W番号・オリジナル番号・参考VSL番号・「A-2｜」の形が無い時は、`_ad_overrides` に「広告ID: 素材の名前」を足します。
3. 集計を出します。`~/.agents/skills/_env/venv/bin/python analyze.py`（足切りは `--min 60000` などで変えられる）。`tools/data/集計.md` が書き直されます。この文書の数字はそこから写して直します。
4. Meta の呼び出し上限（#4）に当たった時は、日別の配信期間と Meta 側の動画の長さだけを取らずに進みます。今回の取得もこれに当たったので、台帳の期間は「未取得（作成日）」と出ています。1時間ほど空けて `update_ledger.py` を回し直すと埋まります。

## 残っている注意

- **同じ時期に限ると、1素材あたりの購入は多くて数十件です**。上の分類（書き出しの種類・段階）は、2026-10-15 に文字起こしを読んで私が付けた物です。見直して `対応表.json` を直せば、集計に反映されます。
- **どの素材がどの時期・どのキャンペーンに出たかが、成績に強く効いています。** 一番の打ち手は、新しい書き出しを同じ日・同じ額の ABO（1本ずつの広告セット）で並べて出す事です。今回の比較で一番信用できたのも、9/28 の ABO テストでした。
- 新ハーネスの素材は、40,000円を超える消化と、vercel 記事の LPV 計測の確認が済んでから、もう一度この文書に入れます。
