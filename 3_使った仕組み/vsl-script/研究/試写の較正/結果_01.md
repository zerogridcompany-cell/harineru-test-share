# 試写 01（A・B・C・E の人として）

**1. 1文目で手を止めますか**
流す。犬とシーツの画で一瞬だけ親指が止まるけど、「シーツの横でしちゃう犬」と聞いて「うちの子はちゃんとシーツでするから関係ない」と思って流す。うちの困りごとは、汚れたシーツを毎日丸めて捨てることと、ごみ箱が臭いこと。トイレの失敗の話には見えない。

**2. 1文ずつ**
実際は1文目で流している。下は、もし流さずに見ていたらどうだったか。
- 1：ここで流す（失敗の話で、うちには当てはまらない）
- 2：次も見る（「保護施設のコツ」は少し気になる）
- 3〜6：ここで飽きる。「使ってくれない」「慣れていない犬」「怖がりな犬」と、しつけの話が続く。うちの子は何年もシーツを使っている
- 7〜11：ここで流す。「疲れ切る」「無視する」「ちぎる」も、うちの子ではない。11の「そんなことはありませんか？」には「ありません」としか言えない
- 12：一瞬だけ止まる。「端っこで」はうちのすみの黄色い跡に少し近い。でも「半分は床へ」まではいかない
- 13〜18：ここで飽きる。施設の話になって、私とは関係がなくなる。18は意味が分からない
- 19〜27：次も見る。ビーグルの話なら聞ける。ただ、やはりしつけの話
- 28〜35：ここで飽きる。また説明に戻る
- 36〜39：「広告か」と分かるところ。39の「手入れのしやすさ」で少し気になる
- 42：ここで止まる。「安いシーツを組み合わせる」って、結局使い捨ても買うの？と混乱する
- 44〜45：**ここがいちばん見たかったところ**。「毎回捨てずに使える」。でも、ここまで見ている人はいないと思う
- 46〜48：ここで飽きる。また施設の話
- 49〜54：ここで流す。「ひんやり濡れた」「シーツの横でしている」と最初の話に戻る。うちの話ではない。終わり方も途中で切れている感じ

**3. 「これは私の話だ」と思った文**
45（毎回捨てずに使える）。少しだけ12（端っこで）と44（洗って再利用）。それ以外は、うちの子ではない犬の話。

**4. 「広告だ」と気づいた文と気持ち**
36（「そこで選択肢になるのが、洗えるワンドライです」）。「施設のいい話かと思ったら、結局売りたいのね」と少し冷める。37の「繰り返し使える布製」で「あ、捨てなくていいのか」と思うので、ほんとうはここで続きを見たくなる。でも、1文目で流しているので、ここまでたどり着かない。

**5. 最後まで見ましたか／リンクを押しますか**
見ていない。押さない。最初から最後まで「トイレを失敗する犬」の話で、私の悩み（ごみが増える、臭い、毎日替える）にほとんど触れていない。45がもし最初に来て「毎朝シーツを丸めて捨てていませんか。ゴミは増えるし臭いし」と言われていたら止まっていたと思う。

**6. 分からなかった言葉・文**
- 18「狙って使えることが役立ちます」：何を狙うのか分からない
- 42「安いシーツを組み合わせるんです」：ワンドライの話の途中で、なぜ安いシーツが出てくるのか分からない。使い捨ても結局要るの？
- 49「2枚を歩いていて」：意味が分からない（「廊下を歩いていて」？）
- 52「うちのシーツ、ルーシーも」：ルーシーは誰？ビーグルの子と同じ？シーツの名前？
- 38「床を守るための構造」：どういう作りか想像できない
- 47「入荷したら」：施設の話なのか、売り込みなのか分からない

**7. 一番心に残った1文／一番いらなかった1文**
- 残った：45「毎回捨てずに使えるのが特徴です。」
- いらなかった：11「そんなことはありませんか？」（ちぎる・無視するなんて、うちの子はしない。「ない」と思った時点で私向けではないと決まってしまう）
