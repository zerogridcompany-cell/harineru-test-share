読まなくていい条件: 土台の変数の名前と既定が分かっていて、`店の印.json` だけを書く回。

**正本はこのファイル（`pdp-tsukuru/references/土台.md`）。** 本人の環境の Vault `ec/構造/型/店/_土台_記事の飛び先.md` はここを指す案内だけ。

殻（HTML）: `node ~/.agents/skills/pdp-tsukuru/scripts/土台を作る.mjs <出力>` が空の型 `~/.agents/skills/pdp-tsukuru/kata/` を写す。段の並びはここちドライ、作りはワンドライ式、中身は〔札〕だけ。下の表の「既定」は形の見本の言葉で、殻の中身ではない。

## 言葉の定義

| 言葉 | 意味 |
|---|---|
| 変わる | 商品・ブランド・客が変わると値が変わる変数（選ぶ所のボタン・説明文は、空の型の作りでスマホは2列・PC は4列に折り返す）。◯ の行は `店の設計.md` の 4 で値と出どころを書き、`店の印.json` に入れる。✕ の行は土台のまま触らない |
| 既定 | 土台（ここちドライ）に入っている値。◯ の行では、出どころが無い時の仮の値ではなく「形の見本」として読む |
| 短い | この文書では「値段を伝えるまでの時間が短い」の意味だけで使う。ページの長さの事ではない |
| 出どころの種類 | その値をどこから取るか。商品の事実／仕入先の数字／記事の約束／記事の残った疑い／客の資料／本人の決め／土台 の7つ。仕入先の数字は仕入先のページにある数字（寸法・素材・評価）で、`product.md` の「出どころ」に「仕入先の数字」と書いた物 |
| 残った疑い | 広告（と記事）を見終わった人が、まだ買わない理由として持っている問い。記事の移植表か `VSLの塗り.md` の「見終わった人の状態」に書いてある物 |
| 記事の約束 | 記事が読み手に言い切った得（例: 見た目はいつもの下着のまま）。店はこれと同じ事を言う。店直行では VSL の「開けた穴」で読み替える |
| 記事の15の事 | 買うまでに頭の中で受け入れる15の事（`構造/型/_買うまでの15の事.md`）を、記事がどこまで言ったかで塗った表。店直行では VSL を塗った表で読み替える |
| オファーを先に見せる店 | 最初の画面で値段とセット（オファー）を見せ、2スクロール目までに見える店。ページの長さでは分けない。この土台の型 |
| 主役 | 写真1枚の中で一番大きく写っている物（商品・人の体・人の顔・図…）。言葉は「段ごとの参考」の節の一覧から選ぶ |
| 参考の写真 | 「段ごとの参考」の表で、その段の参考（ここちドライかワンドライ）の同じ段にある写真の、上から順の主役と文字の有無 |
| 店直行 | 広告から記事を通らずに、店（商品ページ）へ直接来る道。入口は `ec/<商品>/09 店/VSLの塗り.md` |

## 店の型は1つ

型は「オファー（値段とセット）が2スクロール目までに見える店」だけ。店直行（VSL から直接来る）でも同じ型で、最初の画面のすぐ下の段を下の分かれ目の表で選ぶ。
この土台はその型そのもの: 最初の画面に写真・評価・特長4つ・セットと値段・ボタンがあり、スマホで2スクロール目までにオファーが見える。
