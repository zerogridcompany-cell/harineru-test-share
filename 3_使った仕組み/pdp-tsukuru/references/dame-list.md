## A. 触れない・見えない（最優先）

| # | やらかし | 何が起きたか | 検出のしかた |
|---|---|---|---|
| A1 | カートの引き出しに `visibility:visible!important` だけ当てた | `cart-drawer` が `position:fixed; inset:0; z-index:1000` のまま透明なフタになり、**ページ全体が一切押せなくなった** | 全ボタンの中心座標で `elementFromPoint` を取り、自分自身でなければ被っている |
| A2 | スクロール演出のJSを剥がしたのに CSS を戻し切らなかった | `.animate-item{filter:blur(1px)}` が解除されず、ページ下半分がずっとボケたまま | `getComputedStyle(el).filter` に blur が残る要素を全走査 |
| A3 | 非表示の要素に `!important` を足して復活させた | 開いていないモーダル・ドロワーが常時表示になって下の要素を食う | 同上 |

**必ずやる**：ホーム・商品ページ × スマホ390px・PC1280px の4通りで
「押せるはずの要素が何個あって、何個が他の要素に覆われているか」を数える。**覆われ0が合格**。

## C. 数字と価格

| # | やらかし | 何が起きたか |
|---|---|---|
| C1 | レビュー件数が場所ごとにバラバラ | 上部が18,736件、下が558件、注釈が約200件 |
| C2 | 打ち消し価格を「単価×個数」で作った | 2個で¥31,920、3個で¥47,880という誰も信じない数字に |
| C3 | 割引率のバッジが段ごとに違った | 50%OFF と 54%OFF が混在 |

**ルール**：
- 件数・評価は**1つの数字に統一**し、`python3 scripts/面の数字.py --広告 <文字.txt> --記事 <URL> --店 <URL>` が食い違い 0 になるのを確かめる
- **打ち消し価格・比較価格と割引率は、対象商品／プランの実際に確認できる価格の根拠から計算する。** 参照元・対象商品・期間・通常価格／比較基準・販売価格を記録し、広告・記事・店・カートの同じオファーを照合する。根拠が無い時は比較価格と割引表示を載せない。販売価格を2倍にして基準価格を作らない。

> 旧指示（2026-10-04に廃止、事故履歴として保存）：「打ち消し価格＝販売価格×2（＝50%オフ）で全段そろえる。数量で掛け算しない」。現在の合格条件ではない。
- 表示価格が実際にカートに入る金額と一致するかを、許可された非課金テスト／カート検査で全プラン確かめる。決済を確定しない。テスト環境でカートの金額まで見られなかったプランは「未検証」と書いて残す

## D. 画像・動画

| # | やらかし | 何が起きたか |
|---|---|---|
| D1 | カルーセルの文字を1400pxのキャンバス基準で組んだ | 390px幅では6〜8pxになり**読めない** |
| D2 | ヒーロー動画が微かな寄りだけ | 静止画に見えて「動画が入っていない」と言われた |
| D3 | ヒーロー動画に商品が映っていない | 何の店か分からない |
| D4 | 同じファイル名で画像を差し替えた | CDNキャッシュで古い画像が出続けた |
| D5 | 商品ブロックの画像が出ない | `media-gallery` が `display:inline` で高さ0に潰れていた |

**ルール**：
- **1400pxキャンバスの最小フォントは40px**（390pxで約11px）。それ以下の文字は載せない
- 画像を差し替えたら**ファイル名を変える**（`-b` `-v2` を付ける）
- 動画は商品が最初から最後まで画面に入っていること。`autoplay muted playsinline loop` ＋ `preload="auto"` ＋ poster
- ロゴ・ブランド名は**1つに統一**（商品名とロゴが違うのは事故）

## F. 自分で壊す

| # | やらかし |
|---|---|
| F1 | あるセクションを作り替えたとき、**同じ範囲に入っていた別機能の `<style>` と `<script>` ごと消した**（プラン表示・カルーセル制御・価格ルールが同時に死んだ） |
| F2 | 置換の終端が見つからず `find()` が -1 を返し、`s[:a]+new+s[-1+len]` でファイルの大半を複製した |
| F3 | 初期化で `scrollIntoView` を呼び、**ページが読み込み直後に勝手に下へスクロール**した |

**ルール**：
- 広い範囲を差し替える前に**その範囲に他の `id=` 付き style/script が無いか grep する**
- `find()` の戻り値は**必ず -1 判定してから使う**（`assert a!=-1 and b>a`）
- 差し替えた後は、**そのページの全機能をもう一度通しで実測する**（消えたことに気づけるのはそれだけ）
- 初期化時に `scrollIntoView` を呼ばない（ユーザー操作のときだけ）
