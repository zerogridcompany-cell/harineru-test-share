# 見た目の方向を決める（店の道の 2.5）

読む人: 店を作る Claude。
読む時: 店の型を決めた後、変数を埋める前。毎回。
読まなくていい条件: 同じブランドで同じ客の店を直す回（前に決めた方向を `店の設計.md` から写す）。

## なぜこの工程があるか

ここちドライは55歳以上の女性の店なので、柔らかく、花のような見た目にした。客が変われば見た目も変わる。男性なら機械のように硬く、男女どちらもなら中立で物そのものを見せる。**見た目は型で縛らない。客の資料を読んで、毎回決める。**

## 入る物

- 客の資料（うちは `newec_harness/<商品名>/01_商品理解の基盤/K_ペルソナ/<アングル>_<呼び名>.md` と `B_市場と悩みの地図.md` の原文。harness-map）
- 商品の写真と、商品が置かれる場所（浴室・寝室・外）
- 記事の「見終わった人の状態」（今の気持ち）

## 決める物（4欄。`店の設計.md` の「見た目の方向」に書く）

| 欄 | 何を決めるか | 書き方 |
|---|---|---|
| 方向（1文） | この客が、この商品の店を開いた時に「自分のための物だ」と感じる見た目 | 「◯◯な人に、◯◯のように」の1文。例「55歳以上の女性で恥ずかしさが中心の人に、柔らかく、花のように」「40代の男性で道具として選ぶ人に、機械のように、硬く」「男女どちらも・家族が買う物に、中立で、物そのものを見せる」 |
| 色 | 地の色・強調の色・ボタンの色の3つ | 16進で3つと、なぜその色か1行（例: 浴室の商品なら水と清潔の色から外れない） |
| 書体 | 見出しと本文 | 丸い（Zen Maru Gothic）／角ばった（Noto Sans JP）／明朝（Zen Old Mincho）のどれか、または他。なぜか1行 |
| 角と写真の調子 | 角の丸み（丸い／少し丸い／角）、写真の光（明るい／落ち着いた）、寄り（顔まで寄る／全身／物だけ）、人の表情 | 1行ずつ |

4欄それぞれに、**客の資料のどの行から決めたか**を1行添える。資料に無い事で決めない。

## 考える手順（プロンプト。この順に自分に問う）

1. **この客は誰か。** 年代・性別・暮らしの場面を、資料の言葉で3行で言う
2. **この客は、この商品を何として買うか。** 「恥ずかしさを消す物」「道具」「家族への贈り物」「安全の備え」のどれに一番近いか。資料の声を1つ引く
3. **その気持ちに合う見た目は、世の中のどの物に近いか。** 化粧品の箱／工具のカタログ／病院の案内／家電の箱／子ども用品。近い物を1つ選び、その見た目の特徴を3つ言う
4. **4欄に落とす。** 3で選んだ物の色・書体・角・写真の調子を、そのまま4欄に写す（色は16進で3つ、書体は名前で1つ）
5. **確かめる。** 別の AI に、客の3行と4欄だけを見せて「この見た目の店を開いたのは誰だと思うか」を答えさせる。客の年代・性別が当たれば合格。外れたら 3 からやり直す

## 守る線

- 男性向け＝黒と青、女性向け＝ピンク、のような決めつけで止まらない。3 で「近い物」を1つ選ぶ所まで考える
- ブランドに決まった色がある時は、その色は動かさない。動かすのは書体・角・写真の調子
- 見た目を決めても、**段の高さ・画像の場所と大きさ・ボタンの位置は土台のまま**（見た目で変えるのは色・書体・角・写真の調子だけ）
