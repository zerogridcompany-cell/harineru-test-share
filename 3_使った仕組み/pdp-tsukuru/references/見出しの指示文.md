# 最初の画面の見出しの指示文（どの店でも同じ型）

読む人: 店を作る Claude（pdp-tsukuru の手順 5 で「題の型」「副題」を埋める時）。
読む時: 最初の画面の h1 と、その下の1行を書く前。毎回。1枚目の写真の中の見出しを書く時も同じ型で。
読まなくていい条件: 見出しはそのままで、段の中の文だけを直す回。

この型が決めるのは「狙う心理・長さ・入れない物・選び方」まで。**言い回し・切り口・場面は書き手が毎回考えて作る**（`ec/決めたこと.md` 2026-10-18「縛りすぎるとクリエイティブが弱くなる」）。同じ入力から2回書いて違う文が出るのが正しい。

## 関門（通らなければ書かない）

| 関門 | 通る条件 |
|---|---|
| 1 | `店の設計.md` の 1（来た人）の「残った疑い」と「今の気持ち」が埋まっている |
| 2 | 商品の事実（うちは `newec_harness/<商品名>/00_入口.md`・`01_商品理解の基盤/A_商品の事実.md`・`02_損益分岐.md`。harness-map）を開いてある。見出しに出す数字は、ここにある物か `決めた値.md` にある物だけ |
| 3 | 候補を3つ書き、各に「どの心理を狙ったか」を1行で付けてから1つを選ぶ。1つだけ書いて出さない |

## 参考（引く）

### 既定の型: 得が1秒で分かる（どの店もまずこの型で書く）

見出しは「利益がある（得をする）」と1秒で感じる言い方にする。参考はワンドライの最初の画面（`デザインの参考_wandry_2026-10-17.html`）の写真の中の見出し。

| 部品 | 作り | 形の例（言い回しは写さない） |
|---|---|---|
| h1 | 読み手が何度もやってダメだった事（前の失敗）を、その人の言葉で名指しし、それが手間なしで終わる絵で閉じる。20字以内・2行 | 前の失敗＝「何度〜してもダメ」、終わり＝「自分から」 |
| 下の1行 | 得の大きさを「期間か単位 × 金額か回数 ＋ 得の言葉（節約・浮く・いらない・〜円で済む）」で出す。比べる相手の額は書かず、引き算した答えだけ。15字以内・強調色 | 「3年で14万円の節約に。」（11字） |
| そばの数字3つ | 速さ（すぐ効く）・人数か割合（乗り換えた）・金額（浮く額）の3つ。3つ目は下の1行と同じ得の数字をもう1回出す | 「89% 初日から」「5万人超 が切り替えた」「14万円 3年で浮く額」 |

外れの形（残っていたら書き直す）: 下の1行が保証・返金・条件から始まる（保証は1枚目の写真の札とボタンの下の1行が持つ）。h1 が商品の使い方・仕組みの説明で終わる。得の数字が下の1行に無い。

### 狙う心理（読んだ1秒で、次の3つのどれか1つが来る）

| 心理 | 読み手の体で起きる事 | 合う「残った疑い」 |
|---|---|---|
| 損をしない | 「これを選んでもお金も手間も失わない」と感じる | 値段・費用・返品が残っている（値段のわりに得が無いのでは・外れたら損） |
| 自分に価値がある | 「これは自分（家族）に得をくれる」と感じる | 効くか・合うかが残っている（自分の場合にも効くのか） |
| 前の失敗が終わる | 「前に試してダメだった事が、これで終わる」と感じる | 前の物への不信が残っている（前のも同じ事を言っていた） |

参考の h1 は「前の失敗が終わる」、下の1行は「損をしない」を数字で出している（幅 390 で h1 19字・2行、下の1行 11字）。既定の型はこの組み合わせ。他の心理を選ぶのは、残った疑いが「効くか・合うか」だけの時（その時も下の1行は得の数字）

### 長さと形

| 物 | 線 |
|---|---|
| h1 | 20字以内。スマホ（幅 390）で2行まで |
| 下の1行 | 15字以内。得が数字で分かる形（金額・日数・回数のどれか1つ） |
| 1枚目の写真の中の見出し | h1 と別の文。1行＋その下に小さく1行（参考は12字＋1行） |

### 入れない物（入っていたら書き直す）

| 入れない | なぜ |
|---|---|
| 疑いの文・問いの文（「〜でしょうか？」「本当に〜？」） | 読み手の疑いを1秒目に呼び起こす。疑いへの答えは最初の画面のすぐ下の段（土台の分かれ目）が持つ |
| 条件の説明（「〜の場合は」「〜なら」） | 読み終わるまで得が来ない |
| 届く日数 | 届く日数はボタンの下の灰の1行だけに出す（`デザインの参考.md` の「写真と部品の変数」⑥） |
| 商品の事実に無い数字 | 広告・記事・店の数字が食い違う（最終確認 A4） |

## 手順（末尾。この順に）

1. 既定の型（得が1秒で分かる）で書くと決める。`店の設計.md` の 1 の「残った疑い」が「効くか・合うか」だけの時に限り、上の表で別の心理を1つ選ぶ。得の数字の材料（比べる相手の額・1日あたりの額・期間）を `product.md` と `決めた値.md` から先に3つ書き出す
2. 下の指示文の `{}` を埋めて、書き手（自分か Opus のエージェント）に渡す
3. 候補3つを表（h1・下の1行・狙った心理）で受け取り、「入れない物」と「長さと形」の線で落とす。全部落ちたら2からやり直す
4. 残った中から、狙った心理が手順1で決めた心理と合う物を1つ選び、理由1行を `店の設計.md` の 4 の「題の型」「副題」の理由の欄に書く

指示文（このまま渡す。`{}` だけ埋める）:

> {商品名}（{商品の仕組みを1文}）の、商品ページの最初の画面の見出しを書いて。読むのは {客の資料の年代・性別・暮らしを1行}。この人は {残った疑い} がまだ残っていて、今 {今の気持ち}。読んだ1秒で「得をする」と体で感じる言い方にする。h1 は、この人が何度もやってダメだった事（{前の失敗}）を名指しし、それが手間なしで終わる絵で閉じる20字以内。その下の1行は、得の大きさを「期間か単位 × 金額 ＋ 得の言葉（節約・浮く・いらない）」で出す15字以内（比べる相手の額は書かず、引き算した答えだけ）。保証・返金・条件から始めない。そばに置く数字3つ（速さ・人数か割合・金額。3つ目は下の1行と同じ得の数字）も出す。疑いの文・問いの文・条件の説明・届く日数から入らない。数字は次の物だけ使う: {商品の事実の数字}。候補を3つ、各に「どの心理を狙ったか」と「得の数字の出どころ」を1行付けて表で出して。言い回しと切り口は任せる。
